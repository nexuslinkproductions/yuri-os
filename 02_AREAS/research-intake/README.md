# Research Intake

This is the canonical entry point for research capture.
Treat every item here as documentation in progress.

---

## Mission

- Preserve evidence, not just links.
- Separate source facts from interpretation.
- Keep material searchable, dated, and reviewable.
- Promote useful research into the research library when it becomes durable.

## Operating Model

### Vault Direct
Fast capture by writing notes here immediately.
Use this when the source is fresh and speed matters.

### Web Clipper
Use Obsidian Web Clipper in Chrome once `Allow JavaScript from Apple Events` is enabled.
Use this when you want structured capture from the browser.

## Handling Rules

- Every capture should record the source, date, claim, evidence, and next action.
- If the claim is not directly supported, label it as inference.
- Keep intake notes short, but never sloppy.
- Promote mature work into `RESEARCH/` rather than leaving it in intake forever.
- Do not store secrets, credentials, or ephemeral chatter here.

## Triage Levels

- Active: work still being investigated
- Verified: source checked and claim supported
- Synthesized: multiple sources merged into a durable note
- Decisioned: a conclusion or action has been recorded
- Archived: closed and no longer active
