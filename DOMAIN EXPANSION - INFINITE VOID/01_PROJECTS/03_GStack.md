## What is GStack?

GStack is **Garry Tan's exact Claude Code setup** — a comprehensive, opinionated suite of 23 tools designed to serve multiple development roles: CEO, Designer, Engineering Manager, Release Manager, Doc Engineer, and QA.

### Core Philosophy
GStack provides a complete development stack configured with specific tools and workflows. Rather than building from scratch, developers inherit Garry Tan's battle-tested approach to AI-assisted development.

### Key Capabilities

**Leadership Role (CEO)**
- Strategic planning and decision-making
- Project oversight and prioritization
- Stakeholder communication

**Design Role (Designer)**
- UI/UX design workflows
- Design system management
- Visual asset handling

**Engineering Role (Eng Manager)**
- Code quality enforcement
- Team coordination
- Technical debt management

**Release Management (Release Manager)**
- Deployment workflows
- Version control
- Rollback procedures

**Documentation (Doc Engineer)**
- Automated documentation generation
- Knowledge base creation
- API documentation

**Quality Assurance (QA)**
- Testing strategies
- Bug tracking
- Test automation
