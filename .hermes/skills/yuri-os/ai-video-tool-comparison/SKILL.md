# AI Video Tool Comparison

## When to Use

- User asks which AI video tools fit a social media or agency workflow.
- User needs pricing, API, quality, or rendering-speed comparisons.
- User wants a client-ready markdown table or shortlist.

## Procedure

1. Identify the target workflow: ads, shorts, client pitch, concepting, product demo, or post-production.
2. Check current official pricing/API pages first.
3. Compare at least three tools across pricing, output quality, API availability, speed, licensing/commercial fit, and best-use case.
4. Prefer current official docs over blog summaries.
5. Save the report under `~/NUDIMMUD/yuri-os/outputs/` when the user asks for a file.

## Output Format

- Short recommendation first.
- Markdown comparison table.
- Notes for tradeoffs and operational risks.
- Source links.
