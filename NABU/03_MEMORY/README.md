# HOUSE OF MEMORY
*Knowledge persists. Learning compounds. Contradictions are resolved.*

**Purpose:** What we learn survives session boundaries. Rules improve over time.

---

## Three-Layer System

### Layer 1: CLAUDE.md (Always Loaded, Highest Priority)
- Routing logic, workflow definitions, quality standards
- Non-negotiable rules, domain knowledge
- Shared across all sessions

### Layer 2: Auto Memory (MEMORY.md) (First 200 Lines Loaded)
- Session-learned patterns, skill candidates
- Architecture decisions, debugging insights
- Team knowledge, setup quirks
- Pruned monthly (delete stale entries)

### Layer 3: Rules Directory (Path-Targeted)
- Project-specific conventions
- Client preferences, domain rules
- Activate on-demand based on file path

---

## Learning Loop

```
Observation: NOESIS watches blueprint execution
  ↓
Extraction: Pattern repeats 2x → flag as learnable
  ↓
Codification: Write to Auto Memory; test on execution 3
  ↓
Promotion: After 3 successes → promote to CLAUDE.md
  ↓
Deprecation: If conditions change → mark as aging; eventually archive
```
