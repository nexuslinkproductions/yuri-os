# HOUSE OF FUTURES
*Emergence. Evolution. Meta-learning. What's being born?*

**Purpose:** The system improves itself. New patterns lead to new blueprints.

---

## Four Evolution Mechanisms

### 1. CROSS-AGENT PATTERNS
- Watch all agents; notice patterns repeating across domains
- Example: "All cost optimizations involve batching work"
- Example: "All reliability improvements involve adding gates"
- Extract: Rules applicable across all blueprints

### 2. SYSTEM REFACTORING
- Every quarter: can blueprints merge? Are new patterns appearing?
- Blueprint set grows (20 → 25) or shrinks (20 → 15) as patterns shift
- Modular system, not static

### 3. EMERGENCE DETECTION
- Monitor: do agents develop capabilities not in original blueprint?
- Example: Security agent develops better vulnerability explanation (emergent teaching)
- Escalate: flag to NOESIS; decide if systematic
- Integrate: promote emergent behaviors to blueprints if reliable

### 4. TEMPORAL ANALYSIS
- Client behavior: seasonal busy seasons? (holiday campaigns)
- Team rhythm: when does Marcel work longer? (project phase dependent)
- Budget: when are tokens spent fastest? (learning vs. execution)
- Automate: trigger different blueprint sets by season/phase

---

## Growth Triggers

**New blueprint needed when:** Same problem solved 3+ times → codify into blueprint

**Blueprint deprecated when:** Conditions change so much old blueprint breaks → retire + archive

**House expanded when:** New domain emerges → build new House

**Integration revised when:** Two blueprints compose worse than expected → redesign interface
