# HOUSE OF ECONOMICS
*Token cost. ROI. Budget allocation. Forecasting.*

**Purpose:** Understand cost, value, and resource constraints across all operations.

---

## Core Metrics

### Token Budgeting
- Task class → token cost (code review, audit, ideation, support, analysis)
- Model choice → cost/benefit trade-off per task
- Effort calibration → `high` / `xhigh` / `max`
- Monthly budget → allocated by domain

### Cost Tracking
- Weekly ledger: spending, outcomes, variance
- ROI per blueprint: automation value vs. agent cost
- Model selection: when Sonnet suffices vs. Opus needed

### Forecasting
- If scale from 2 to 5 clients: how does cost scale?
- If add 3 team members: token budget change?
- If deploy 50 agents: total monthly cost?

---

## Budget Structure (Example: $500/month)

- Daily triage + PR automation: $150 (30%)
- Code reviews + security: $120 (24%)
- Creative research + ideation: $80 (16%)
- Scheduled routine work: $80 (16%)
- Learning + experimentation: $70 (14%)

---

## ROI Calculation Pattern

```
Blueprint: [Name]

Cost:
  - Setup (one-time): $X
  - Monthly running: $Y
  - Value from automation: $Z/month

ROI: $Z / $Y = Multiplier
Payback: N weeks/months
```
