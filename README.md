## Key Concepts

### The Eco-System: Three Vaults, One Network

This repo is one node in a **three-vault ecosystem**:

1. **NUDIMMUD** (this vault) — Marcel's operational system
   - Primary: on-set capture execution, location management, portfolio
   - Shared: project briefs, shoot logistics, client communication
   
2. **c2moviez-vault** (Claudio's vault) — Creative agency + digital services
   - Primary: post-production, motion graphics, VFX, client management, invoicing
   - Shared: final deliverables, project briefs, asset pipelines

3. **iC2M** (planned) — Cross-vault integration space
   - Shared project files (read-only references from both vaults)
   - Unified client brief system
   - Cross-pipeline communication logs

**How they work together:**
- Marcel captures on-set: writes shoot log, embeds reference footage
- Shares brief + metadata to c2moviez (via NETWORK-SYNC)
- Claudio receives, begins post + motion graphics
- Both vaults reference same project via unique slug (e.g., `ANGELIKA_2026-02`)
- Final deliverable linked back from both vaults
