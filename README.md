# YURI-OS-MUSUBI — Operator System

**Marcel Spatz · Nexus Link Productions · Vienna**

---

YURI-OS-MUSUBI is a unified operator system for running creative, technical, and business workflows from a single surface. It combines video production pipeline management, AI agent infrastructure, financial operations, and premium tooling design into one integrated command center — not a second brain, not a collection of vaults, but a live operational system.

The name: **MUSUBI** (結び) — the binding force. The principle that connects domains, timelines, people, and creative energy into a coherent whole. That is what this system does.

## Agent Infrastructure

The system runs a persistent agent layer:

- **Yuri Sentinel** — autonomous background daemon (33-min heartbeat), health monitoring, signal gathering, memory synthesis
- **Codex** — primary implementation agent operating under CLAUDE CONTROL PACKET protocol
- **DeepSeek** — analysis, reasoning, and parallel implementation lane
- **Pulse Cortex** — per-turn complexity classification and advisor dispatch
- **GitNexus** — code intelligence: impact analysis, symbol graph, execution flow mapping

All agents operate under authority-bounded contracts. Claude Code is the control plane and final authority.
