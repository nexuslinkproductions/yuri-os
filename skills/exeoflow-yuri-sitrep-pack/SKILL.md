Use this skill to turn an interactive briefing page into a reusable design source pack.

   - `03_RESOURCES/References/design-packs/exeoflow-yuri-sitrep-baseline/companion-nexus-link-website.md`

   - `03_RESOURCES/References/design-packs/exeoflow-yuri-sitrep-baseline/comparison-exeo-vs-nexus-link.md`
4. Apply the reuse guide:

## Workflow

- Capture the current artifact as a baseline.
- Add the stronger benchmark as a companion reference.
- Write a short manifest with load order and guardrails.
- Add a comparison sheet with copy/improve guidance.
- Keep all future versions readable, lawful, and reusable.

## What To Preserve

- Consumer-readable story flow.
- Clear reading hierarchy.
- Real-world map interactions.
- Public-source evidence structure.
- Official company contact routes only.

## What To Improve

- Cleaner typography and spacing.
- Less visual clutter.
- Stronger motion and transitions.
- Better map presentation.
- More editorial framing and package close.

## Guardrails

- Public sources only.
- No private personal data.
- No leaked or credentialed data.
- No intrusive surveillance behavior.
- Treat the baseline as a starting point, not the end state.
