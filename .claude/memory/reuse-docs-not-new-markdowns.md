RULE: Reuse and update the existing doc in place; do not create a fresh markdown when an existing one can hold the content. WHEN: writing any plan, report, handoff, standpoint, or notes where a doc already covers the topic. DO: rewrite/extend the existing file (e.g., fold a fresh-session handoff INTO the operation plan, update the resume memory in place). DONT: spawn handoff-v2 / standpoint-2026 / a parallel doc — it wastes space, sprawls, and creates confusion over which is canonical. WHY: Marcel corrected this 2026-06-02 after I created native-only-fresh-session-handoff.md when the existing plan doc was the home; he said it applies in general, not just that run. SEE: this is the doc-creation face of rework-in-place-not-parallel.
