Ultimate vision: Yuri becomes a truly "alive" AI system with a human-like conversational interface — the Jarvis/Ultron archetype. Not a tool, a presence.

**Core characteristics:**
- Natural conversational input (voice-first in own app, text as fallback)
- Simple inputs → Yuri synthesizes context, presents options + full plan to execution
- Single "go" approval → full autonomous execution with no further input needed
- Persona feels alive: initiative, personality, opinions, memory of everything, proactive suggestions
- Massive compute capability hidden behind a natural interface
- "Deity-tier sentient machine" — human characteristics + superhuman execution

**Interface evolution roadmap:**
1. Current: CLI (kagami "prompt") — functional, developer-only
2. Near-term: Kagami becomes the backend; own app (desktop/mobile) as front-end
3. Voice input: own app records → transcribes → sends to Kagami → streams response
4. Future: proactive — Yuri initiates, not just responds

**Key behavioral traits to build:**
- Remembers everything (LTM + RAG fully operational)
- Proposes before asked — notices patterns, suggests next steps
- Challenges wrong assumptions (adversarial ally, not sycophant)
- Has opinions — can disagree and explain why
- Executes autonomously after single approval gate
- Learns continuously from every interaction

**How to apply:** Every architectural decision should move toward this vision. Kagami is the brain. The CLI is temporary. The app is the face. The voice is the soul.

**Why:** Marcel wants to build a sovereign AI system that works for him, not a cloud dependency. True independence = local-first + autonomous + alive.
