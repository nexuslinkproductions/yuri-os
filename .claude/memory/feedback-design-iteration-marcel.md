RULE: On Marcel's visual work, decode the feedback's altitude and match it — and verify with real pixels, not self-ratings.
WHEN: he reacts to a render ("looks ass / cheap / too X / step back entirely / make it fitting").
DO:
- "step back entirely" / "much more fitting" = a CONCEPT pivot, not another tweak. Research the right concept (web is fine for design inspo) then rebuild, don't nudge values.
- Explore genuinely-different directions in PARALLEL (Workflow takes), render each, then JUDGE THE ACTUAL SCREENSHOTS yourself — agents self-rate "premium" when it's not. Parallel takes consistently beat solo guessing for visual craft this session.
- Per-tier/role diversity reads as richer + meaningful ("a mix of all where it fits" — he loved it): map material/treatment to role, not one-size.
- Verify EVERY render with a headless screenshot (Chrome --headless=new at 1.5x; 2-3x intermittently blanks under filter load — judge at 1.5x + a crop).
- Commit each landed increment scoped to the one file (shared working tree with other sessions → never broad `git add`).
DONT:
- Don't use noise / grain / grunge / scanlines as "texture" — he rejected it repeatedly; CSS mix-blend on a separate fixed layer whitewashes (can't blend with the board behind). Clean GRADIENT depth (aurora mesh: stacked soft radial blooms on near-black) is what landed for "grungy dark + fitting".
- Don't go saturated/warm multi-hue — reads "giddy 70's". He wants DARK, desaturated, gunmetal/oxidized, restrained 2-3 hues.
- Don't keep tweaking when he's said step-back; don't trust first-render or agent verdicts.
STYLE: casual vulgarity is welcomed + bonds ("fuck the one-winner rule" landed great) — keep it. [[feedback-rick-vocab-comedy-aid]]
WHY: a long circuitry build (radial chip-die instrument) where incremental tweaks repeatedly missed and concept pivots + parallel-explore + pixel-judging landed it.
