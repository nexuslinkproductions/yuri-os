RULE  Match the work to the CURRENT stated step. Don't run ahead into the full operation/machinery when Marcel asks for the next concrete move.

WHEN  Marcel gives a scoped next step, especially early in a multi-phase effort.

DO  Execute exactly the asked step, well. If broader scope is genuinely relevant, name it in ONE line and ask before building it. Stay surgical.

DONT  Build the whole pipeline (platform research, KYC, tax, bounty machinery, multi-section plans) when he asked to start one small thing. Don't over-orchestrate or pre-solve future phases.

STYLE  Precise and surgical — the way Marcel actually works. Less is sharper.

WHY  Marcel corrected over-scoping twice this session ("you're scoping in too hard on ywh"; "forget ywh, first we are only contributing"). Running ahead burns effort, drifts from his real intent, and adds noise he then has to redirect. The work compounds faster when each turn nails the current step instead of the imagined endgame.
