RULE: Layout for Marcel's design work follows Ma (間) — charged negative space that ORGANIZES meaning — NOT a uniform "one-section-per-scroll" rhythm that reads like a premium slide deck/PowerPoint. Vary the layout rhythm; let asymmetry, vertical rhythm, and intentional intervals carry the composition. Palette aligns with wabi-sabi/kintsugi (gold joinery + verdigris patina of age).
WHEN: any multi-section page, report, dashboard, or presentation layout.
DO: asymmetric, breathing, ma-driven composition; vary section structure (don't repeat the same block); consider content-/math-driven generative layout (golden-ratio, modular asymmetric grids); ground in _SYSTEM knowledge-base japanese-aesthetics.md; un-box (space + type + line over hard cards).
DONT: stack identical full-width boxed sections one after another; one-point-per-screen sparse slide rhythm; over-box content.
WHY: Marcel loves Japanese graphic design + has layout docs; the slide-deck rhythm bores him; Ma is structurally aligned with his cognition (japanese-aesthetics.md). He floated math-generated layouts.
