FACTS (triples):
- capability-registry IS `_SYSTEM/capabilities.json` (function-indexed NEED->MECHANISM; **25 capabilities** across 22 mechanism files as of 2026-06-13).
- ENFORCED: the pre-commit hook (`_SYSTEM/git-hooks/pre-commit`, the real target of the `.git/hooks/pre-commit` symlink) now runs `capability-scan.mjs --check` (set -e → exit 1 on stale aborts the commit) — the registry can no longer silently drift. Added after the skill-registry check.
- registry IS auto-generated BY `_SYSTEM/Scripts/capability-scan.mjs` FROM `@capability:` annotations at each mechanism (`// @capability/@serves/@does/@use/@exports`). `--check` is a stale-guard.
- recall TOOL IS `node _SYSTEM/Scripts/capability-recall.mjs "<need>"` (returns the existing mechanism for a need).
- `xref-query.mjs` AUTO-SURFACES `⚡ YURI ALREADY HAS` capability hits ABOVE file hits (fail-open: bad registry → xref behaves as before).
- mandate IS `.claude/rules/capability_first.md` + a trigger line in CLAUDE.md "Brain & Body": before building any new primitive, run capability-recall first.
- 25 registered (2026-06-13 sweep + annotation batch): the 8 originals (fuzzy-cross-surface-match, unfinished-work-attention, energy-gate-scoring, artifact-placement-staleness, text-to-math-decode, event-capture-threading, code-navigation-search, structural-centrality) + quantum-hypothesis-simulation + the eval-processing layer (streaming-aggregator · crn-paired-delta · sequential-stopping · heldout-split) + robust-decision-sim (decision-sim) + izanagi-decision-bridge + the batch: prediction-ledger · propagation-scan · transfer-distance · formula-foundry · math-kernel · math-proof-gate · golden-ratio-primitives (yuri-phi) · spreading-activation-memory · truth-maintenance · claim-evidence-cortex. See [[ref-simulation-arsenal]].

IMPLICATION: before building/importing a new scorer/matcher/gate/loop/parser, run capability-recall (or just xref — it auto-fires). If a capability serves the need, USE/extend it, don't rebuild. When shipping a NEW reusable mechanism, add the `@capability` annotation block + run capability-scan.mjs. This is the inverse of the local-first research mandate, for code. Born from the irys investigation where 4 "innovations" already existed in YURI but weren't surfaced by function.
