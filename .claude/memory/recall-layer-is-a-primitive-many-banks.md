GOAL: build the RECALL LAYER as a reusable YURI primitive, not a one-off code feature.
The pattern (abstracted from the code-bible): mechanism-tagged corpus → calibrated-precision match →
announce-compact / pull-full → gated auto-surface. Code is just the FIRST bank.

WHO: Marcel (saw the generalization live, "hell yes" + "im sure that can be applied to other organs/functions/mechanisms too").

THE TWO RECALL MODES (per [[yuri-navigation-layer-guides-are-skills]] design):
- PULL (build first, zero risk): `ai bible "<mechanism>"` / recall verb → top-K mechanism-matched; zero context cost until called.
- PUSH/AUTO (second, after calibration): deterministic cheap index probe per task → ONE-LINE pointer on a STRONG
  match above a confidence floor (bias to silence) → full payload opt-in. Never auto-inject. Precision over recall:
  a missed surface is harmless, a wrong one costs context + trust.

BANKS THAT PLUG INTO THE ONE LAYER (don't build 8 up front — layer once, prove on code, then snap banks on):
- code exemplars (= [[coding-excellence-corpus]], the code-bible) — bank #1, clean signal
- Foundry formula bank-cards — data already exists
- proven mechanism-transfers (transfer-distance A→B successes)
- the HARDENING CANON (the red-team is producing this bank's material right now)
- design exemplars (component catalog + design-memory, already half this shape)
- MEMORY.md itself is already this pattern (compact index → pull full on trigger)

ANTI-MUDDY DISCIPLINE (Marcel's standing concern, now at N banks): ONE tagging schema + ONE calibrated precision
model across ALL banks, or cross-bank ranking returns garbage (a code-match and a formula-match on different
confidence scales). Cross-scale comparability is ALREADY cracked — the containment+RRF shared-global-space work
([[cross-surface-comparability-cracked]]) is exactly what makes "0.4 in code-bank == 0.4 in formula-bank" hold.

STATE: design agreed 2026-06-09; the recall layer == the navigation layer's true identity (yuri-traverse stops
being "route to an organ", becomes "recall the right proven thing — code/formula/mechanism/pattern — precisely").
NEXT: build code-bible pull-recall (phase 1) after the red-team lands; wire auto-surface onto the navigation
layer's calibrated precision (GVF C-layer) when that exists. SEE [[cross-reference-engine]] (the unifying spine).
