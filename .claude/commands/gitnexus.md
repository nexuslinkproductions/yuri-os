Invoke the gitnexus dispatcher.

Usage: /gitnexus <cli|guide|explore|debug|pr-review|impact|refactor>

Subcommands:
- cli: run GitNexus CLI commands such as analyze, status, clean, wiki, and list.
- guide: show GitNexus tool/resource/schema reference.
- explore: find execution flows and architecture context.
- debug: trace failures and suspicious execution paths.
- pr-review: assess pull request risk and missing verification.
- impact: run blast-radius analysis before symbol edits.
- refactor: rename, extract, split, or move code with graph awareness.
