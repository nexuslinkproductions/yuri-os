# /ds-flash

Quick offload to DeepSeek V4 Flash (fast, no thinking).

**Usage**: `/ds-flash <prompt>`

Alias for: `/offload deepseek-v4-flash <prompt>`

**Examples**:
```
/ds-flash "Summarize this paper"
/ds-flash "Extract entities from the text"
/ds-flash "Write a quick bug report"
```

Best for: extraction, summarization, fast tasks (4K tokens, 60s timeout).
