# /tokenmaxxing

Invoke the `tokenmaxxing` skill to activate full token efficiency mode.

## Usage

```
/tokenmaxxing
```

Engages: ultra-caveman prose, offload-default task routing, auto-compact at 60% context, and background task spawning via `ctrl+b`.

## Mode

Use this to **re-activate** tokenmaxxing after a `tokenmaxxing off` command. By default, tokenmaxxing is active from session start (injected via `token-session-init.js`).

## Behavior Authority

Complete rules for ultra-caveman style, offload routing priority, auto-compact triggers, and subagent execution are in `.claude/skills/tokenmaxxing/SKILL.md`.
