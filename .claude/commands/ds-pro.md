# /ds-pro

Offload to DeepSeek V4 Pro (thinking enabled).

**Usage**: `/ds-pro <prompt>`

Alias for: `/offload deepseek-v4-pro <prompt>`

**Examples**:
```
/ds-pro "Design a caching strategy for this system"
/ds-pro "Reason through this architectural decision"
/ds-pro "Review this code for security issues"
```

Best for: reasoning, code review, complex analysis (8K tokens, 120s timeout, thinking enabled).
