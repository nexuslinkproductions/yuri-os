**Triggers:** `end of transmission` (semantic), `/eot`, `/end-of-transmission`

The command runs a 9-phase evidence-based reflection pipeline:
0. Freeze active work
1. Evidence inventory (files, tool calls, errors, assumptions)
2. Timeline backtrack
3. Claim double-check (verify "done" claims against evidence)
4. Success/failure ledger
5. Could-have-done-better review
6. Skill refinement patches (specific, triggerable, testable)
7. Self-improvement system update (or patch proposal if unsafe)
8. Next-session boot packet
9. Sonnet 4.6 auto finalisation

**Artifacts** written to `.claude/eot/YYYY-MM-DD_HHMM/` (5 files).

**Why:** Replaces casual end-of-session summary with an auditable, evidence-backed reflection system that converts session learnings into reusable skill updates and produces a boot packet for the next session.

**How to apply:** When user says "end of transmission" — freeze work, load the skill, run all 9 phases. Do not summarise casually or invent accomplishments.
