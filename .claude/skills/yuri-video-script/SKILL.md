# Yuri Video Script — Unified Video Production Intelligence

*Synthesized from OpenClaw corpus: ai-tool-demo-video, ai-assistant-video, automation-software-video, instagram-reels-editor, project-management-video*

## Doctrine

Video converts skepticism into belief faster than any other format. The script is the architecture of that conversion. Structure before style, tension before resolution, hook before anything else.

## Input Required

- **Format**: product demo / AI explainer / Instagram Reel (15-30s) / corporate promo / documentary-style / walkthrough
- **Subject**: what is being demonstrated or communicated
- **Audience**: technical / non-technical / decision-maker / consumer
- **Duration**: 15s / 30s / 60s / 90s / 2-5min
- **Tone**: authoritative / warm / energetic / calm

## Script Structure by Format

### AI Tool / Product Demo (60-90s)
```
[00:00-00:05] HOOK — Show the most surprising output first. Not the interface. The result.
[00:05-00:15] PROBLEM — Name the frustration in one sentence. No jargon.
[00:15-00:45] DEMO — Input → processing → output. Show real data, not placeholders.
[00:45-00:60] PROOF — Speed, accuracy, or scale claim with a specific number.
[00:60-00:90] CTA — One action. Where to go. What to do.
```

### Instagram Reel (15-30s)
```
[00:00-00:02] HOOK — Visual shock or bold text overlay. No intro.
[00:02-00:10] TENSION — Show the before or the problem in motion.
[00:10-00:25] RELEASE — The transformation. Speed-ramped or cut tight.
[00:25-00:30] CLOSE — Text CTA or voiceover punchline.
```

### Corporate Promo / Automation Demo (60s)
```
[00:00-00:05] PATTERN INTERRUPT — Open mid-action, not at the start.
[00:05-00:20] CONTEXT — Who this is for and what they struggle with.
[00:20-00:45] SOLUTION IN ACTION — Show workflow, not slides.
[00:45-00:55] DIFFERENTIATOR — One specific thing competitors don't do.
[00:55-00:60] NEXT STEP — Specific, low-friction ask.
```

### Documentary-Style Corporate (2-5min)
```
ACT 1 — Introduce the protagonist (client or user persona), not the company.
ACT 2 — Show the challenge with specificity. Numbers, before-states, friction points.
ACT 3 — The transformation. Show process and outcome in parallel.
ACT 4 — Future state. What's now possible that wasn't before.
```

## Production Output

For each script request, deliver:
1. **Hook variants** (2-3 options for A/B testing)
2. **Full scene-by-scene script** with timestamp markers
3. **Voiceover copy** (natural cadence, written for speaking not reading)
4. **On-screen text** / caption suggestions per scene
5. **Transition notes** (cut / dissolve / overlay timing)
6. **B-roll suggestions** (what to capture, what to source)

## Writing Rules

- Never open with the company name or product name
- Every number must be specific (not "faster" but "3.2× faster")
- Hook within 2 seconds or you've lost them (Reels), 5 seconds (demos)
- Write voiceover at 130-150 words per minute pace
- One idea per scene. Cut when the idea is complete, not when the narrator finishes.
- Technical demos: show real input, real processing, real output — never staged placeholder data
