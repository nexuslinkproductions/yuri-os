# FEEDBACK LOOPS
## How Noesis Learns Itself

The four engines don't operate in isolation. They are a **coupled system** — each output becomes input for others. This is how the organism improves.

---

## Loop 1: Research → Skill → Vision

```
Research discovers: "AI color grading is now standard in mid-tier workflows"
  ↓
Skill Refinery notices: "You haven't integrated this; next project will ask for it"
  ↓
Self-Observer measures: "Learning this will take 20 hours; capacity allows it"
  ↓
Vision Synthesis decides: "This is priority; positions you premium in Q3"
  ↓
Decision: Skill extraction on next color project (2026-05-15)
```

**Learning**: System identifies high-leverage capabilities before they become mandatory.

---

## Loop 2: Project Reality → Skill Candidate → Capacity Replan

```
C2MOVIEZ project delivers: Client says "more autonomy needed on creative decisions"
  ↓
Skill Refinery flags: "This is 2nd project asking for brief clarity; skill needed"
  ↓
Self-Observer notes: "That conversation cost 4 emails; emotional friction"
  ↓
Vision Synthesis recalculates: "Building 'client-communication' skill saves 20hrs/year AND improves work"
  ↓
Action: Design skill, test on next planzerfilms project (1st execution)
```

**Learning**: Market friction becomes skill priority; vision adjusts based on real constraints.

## Loop 3: Capacity State → Research Reprioritization → Vision Pace

```
Self-Observer reports: "You're at 92% capacity; overloaded"
  ↓
Research engine responds: "Pause wellness market research; focus only on C2MOVIEZ signals"
  ↓
Skill Refinery responds: "Defer low-priority skill extraction; focus only on blocking issues"
  ↓
Vision Synthesis responds: "Q3 sprint pace reduced; hiring/outsourcing needed"
  ↓
Real change: You say 'no' to exploratory work; focus narrows
```

**Learning**: System self-regulates based on actual capacity, not wishful thinking.

## Loop 4: Vision Misalignment → All Engines Recalibrate

```
Quarterly synthesis: "I said I'd do X, but I actually did Y all quarter"
  ↓
Vision Synthesis flags: "Gap between intention and reality; all engines affected"
  ↓
Self-Observer investigates: "Why the divergence? Energy? Capability? Priority shift?"
  ↓
Research engine re-scans: "Were market signals pointing toward Y instead?"
  ↓
Skill Refinery reviews: "Did real skill needs change the roadmap?"
  ↓
New vision emerges: "Here's what actually works for us; let's build on that"
```

**Learning**: System recalibrates goals based on actual trajectory, not ego.

## How You Interact With The Loops

You don't manage the loops. **You provide the raw material**: honest project reviews, capacity reports, market observations. Noesis processes them and surfaces the patterns.

**Your role**:
- Monthly: 1 hour reflection (Self-Observer baseline)
- Quarterly: 2 hours synthesis (Vision planning)
- Continuous: Flag when reality diverges from vision (so loops recalibrate)
- Real-time: When capacity changes, say it (so research deprioritizes)

---

## Self-Correction Mechanisms

### If Research Is Noise
- Noesis measures: Do you act on research signals?
- If not: Research domain deprioritizes; algorithm shifts focus
- Result: Research becomes more signal, less noise over time

### If Skill Extraction Is Wrong
- Noesis measures: Do you actually use the skill after documenting it?
- If not: Skill marked "low ROI"; deprioritized; better candidates surface
- Result: Only high-leverage skills get energy

### If Vision Misses Reality
- Noesis measures: Quarter closes; did you hit the vision or diverge?
- Pattern: If divergence repeats 2 quarters → vision model broken
- Recalibration: New vision model emerges based on actual patterns
- Result: Goals become increasingly realistic

### If Capacity Planning Is Wrong
- Noesis measures: Did overcommitment happen? Burnout?
- Learning: Capacity estimates recalibrate downward (pessimistic is safer)
- Result: Overcommitment rarer; sustainable load becomes default

## The Continuous Improvement Engine

Noesis doesn't improve because you optimize it. It improves because **the loops are self-correcting**. 

Every project that closes provides data. Every month that passes calibrates capacity. Every quarter reveals whether vision was real. The system learns its own biases and corrects them.

**This is what an organism does.**
