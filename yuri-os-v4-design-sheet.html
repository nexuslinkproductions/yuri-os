02 / 07 — DUALITY
MIRROR AXIS · NOT TOGGLE

ConceptThe mirror, not the switch

Earlier iterations expressed the Authority Tree and the Data Flow as separate views. A toggle was proposed; the user rejected it. Instead, the canvas is bisected by a vertical spine at x = 960px. The left half renders the authority hierarchy; the right half renders the data fan-out. The two are not alternatives — they are the same system seen from opposing directions.

Left · Authority Tree

ENKI at the top spine. OPENCLAW, HERMES, ARGUS, OBLITERATUS, CASSANDRA, SWARM, OC_AGENT branch downward as a canonical tree fan-out — every gold edge denotes invocation authority. Severity bound at the OPENCLAW node (bridge_advisory cap, HIGH).

  • edgesolid gold
  • directionenki ↘ leaves
  • node-shapehexagon (sealed)

Right · Data Flow

The same agents render again, mirrored across the spine. Edges are abzu-deep blue dashes — marching dashes when active. Direction follows the actual cortex pulse path: DEEPSEEK → OPENCLAW preflight → HERMES → CASSANDRA → SWARM → OBLITERATUS gate.

  • edgedashed abzu-deep
  • directioncortex pulse
  • node-shapecircle (open)

The spine

Single 1px luminous line at x = 960. Color #D4AF37 at opacity 0.7, dashed 4 3. The same node renders on both sides of the spine; the spine is the reflection plane. Hovering a node on one side highlights its mirror on the other. There is no “flip” — the duality is permanent.

Authority and information are the same thing rotated 180°. The mirror axis admits this directly.

05 / 07 — TYPE & MOTION
DARK NETFLIX LIFTS

DisciplineSingle-weight, single-curve, fluid

Dark Netflix (dark.netflix.io) was studied as a duality reference; three patterns were extracted and applied here. The patterns are not the design — they are the discipline imposed on it.

Type · weight 300 universal

Every glyph in the system is font-weight: 300 — display, body, mono. Hierarchy is built by size and color, never by weight. JetBrains Mono for technical text; Inter for everything else. Letter-spacing tightens at display sizes (-0.015em), widens at micro labels (0.1em).

Motion · single easing curve

cubic-bezier(.455,.03,.515,.955) — the only timing function in the system. Hover transitions 240ms, layer reveals 480ms, ambient pulse 2400ms sinusoidal. No bounces. No spring. The curve is a held breath, not a snap.

Fluid · clamp() sizing

All major typography uses clamp(min, fluid, max). The instrument scales with viewport without breakpoints. Display: clamp(28pt, 4vw, 44pt). Body: clamp(10pt, 1.2vw, 12pt). Labels remain pinned at 9pt.

Symbol · triquetra

The triquetra (triple-arc knot) appears at the spine head — a single 24px glyph in gold (#D4AF37). It echoes the three radial arcs and the three-state mirror (left / spine / right). Used once per view, never as decoration.

No toggle, no menu, no chrome

The instrument has no settings panel, no nav bar, no top chrome. State is read by looking at the system, not by clicking into menus. Everything is on-canvas. The only DOM overlays are the right-drawer (on click) and the tooltip (on hover).

A workshop hammer has no settings panel. Yuri OS is an instrument, not a product.
