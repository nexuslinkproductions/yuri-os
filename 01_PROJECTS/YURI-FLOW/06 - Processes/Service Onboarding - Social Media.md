# Service Onboarding: Social Media Management

## When to Use
Client has signed off on Social Media Paid or Organic package.

## Setup (Week 1)

### Account Access
- [ ] Request client's Instagram/Facebook/TikTok login or Business Manager access
- [ ] Get added as admin/editor on Meta Business Suite
- [ ] Connect accounts to scheduling tool
- [ ] If Paid: set up Meta Ads Manager, request ad account access
- [ ] If Paid: confirm monthly ad budget with client (separate from management fee)

### Strategy
- [ ] Schedule strategy meeting (Cal.com)
- [ ] Record meeting (ops.c2moviez.com)
- [ ] Define content pillars (3-5 themes)
- [ ] Define posting frequency (e.g. 3x/week feed, 5x/week stories)
- [ ] Define brand voice & visual guidelines
- [ ] Create post topic calendar (first month)
- [ ] Get client approval on strategy

### Plane.so Setup
- [ ] Create project/module in Plane.so
- [ ] Create recurring monthly tickets:
  - Post topic calendar
  - Content creation batch
  - Community management
  - Monthly reporting
  - If Paid: Ad campaign setup & optimization

## Monthly Cycle

### Week 1: Planning
- [ ] Create post topic calendar for the month
- [ ] Source/create visual assets ([[04 - Team/Besim|Besim]] for graphics if needed)
- [ ] Write captions & hashtag sets
- [ ] Client approval on calendar

### Week 2-3: Execution
- [ ] Schedule posts
- [ ] Publish stories
- [ ] Daily community management (comments, DMs, engagement)
- [ ] If Paid: launch/optimize ad campaigns
- [ ] If Paid: monitor ad spend vs budget

### Week 4: Review
- [ ] Pull analytics (reach, engagement, follower growth)
- [ ] If Paid: ad performance report (CPC, CPM, ROAS)
- [ ] Create monthly report for client
- [ ] Strategy adjustment meeting if needed
- [ ] Plan next month
