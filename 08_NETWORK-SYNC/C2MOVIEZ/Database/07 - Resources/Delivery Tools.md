# Delivery Tools

> [!cti] File delivery pipeline — current tools + future ExeoFlow migration

## Current Stack

### Frame.io — Video Delivery
- **Used for:** Final video deliveries, client review & approval
- **Flow:** CTI edits in Premiere/DaVinci → uploads to Frame.io → client reviews with timecoded comments → CTI applies revisions → final approval
- **Clients using:** All video clients ([[02 - Clients/BOV - Boviro Security AG|BOV]], [[02 - Clients/SHI - SHIPSTER AG|SHI]], [[02 - Clients/GANZ - GANZ BOATS AG|GANZ]], [[02 - Clients/GRYD - GRYD SWISS|GRYD]], [[02 - Clients/BABA - Schafmilchkäserei Koster GmbH|BABA]], [[02 - Clients/RIBO - Carosserie RIBO GmbH|RIBO]])
- **Who manages:** [[04 - Team/CTI - Claudio Tinner|CTI]], [[04 - Team/Marcel - NexusLinkProductions|Marcel]] (Austria)
- **Tip:** Always create a new project per client per deliverable

### Pixieset — Photo Delivery
- **Used for:** Photo galleries, client selection, downloads
- **Flow:** CTI shoots → culls & edits in Lightroom → uploads gallery to Pixieset → client selects favorites → final edits → download enabled
- **Clients using:** All photography clients ([[02 - Clients/UPG - UPGREAT AG|UPG]], [[02 - Clients/GANZ - GANZ BOATS AG|GANZ]], [[02 - Clients/BOV - Boviro Security AG|BOV]])
- **Who manages:** [[04 - Team/CTI - Claudio Tinner|CTI]]

### SharePoint — File Sharing
- **Used for:** Documents, brand assets, project files, IT deliverables
- **Flow:** Files organized in client folders → shared via link or direct access
- **Clients using:** [[02 - Clients/MFB - Med For Balance GmbH|MFB]] (primary), IT clients
- **Who manages:** [[04 - Team/CTI - Claudio Tinner|CTI]]

### Meta Business Suite — Social Media
- **Used for:** Scheduling & publishing social media content
- **Flow:** [[04 - Team/Fanny|Fanny]] creates content → sends directly to client for review → publishes via Meta Business Suite
- **Clients using:** [[02 - Clients/MFB - Med For Balance GmbH|MFB]], [[02 - Clients/SHI - SHIPSTER AG|SHI]], [[02 - Clients/GANZ - GANZ BOATS AG|GANZ]], [[02 - Clients/KAP - Kappiserie GmbH|KAP]]
- **Who manages:** [[04 - Team/Fanny|Fanny]]
- **Note:** No internal approval flow yet — content goes direct to client. Needs process.
