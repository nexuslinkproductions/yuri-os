# Client Onboarding SOP

## Trigger
New lead confirmed via referral or inbound

## Steps

### 1. Initial Contact
- [ ] Receive lead (referral / inbound)
- [ ] Send intro message or call
- [ ] Schedule discovery meeting via **Cal.com**

### 2. Discovery Meeting
- [ ] Record meeting via **ops.c2moviez.com** (Whisper.ai transcription)
- [ ] Create meeting note: [[09 - Templates/Meeting|Meeting Template]]
- [ ] Identify scope, budget, timeline

### 3. Create Client Profile
- [ ] Create client note in `02 - Clients/` using [[09 - Templates/Client|Client Template]]
- [ ] Fill in contact info, source, industry

### 4. Create Project
- [ ] Create **Plane.so** project with modules
- [ ] Create project note in `03 - Projects/` using [[09 - Templates/Project|Project Template]]
- [ ] Link client note to project note
- [ ] Assign team members

### 5. Proposal & Agreement
- [ ] Draft proposal / offer (use `sales_offer_template` if applicable)
- [ ] Send to client
- [ ] Get signed agreement

### 6. Kickoff
- [ ] Schedule kickoff meeting
- [ ] Brief team (Fanny, Besim, Silas as needed)
- [ ] Set up Plane.so tickets for first sprint
- [ ] Start time tracking in ExeoFlow (when live)

## Handoff
Project is now tracked in [[06 - Processes/Campaign Workflow|Campaign Workflow]]
