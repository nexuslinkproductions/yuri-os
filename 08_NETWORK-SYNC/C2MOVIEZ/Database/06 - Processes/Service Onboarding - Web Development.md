# Service Onboarding: Web Development

## When to Use
Client needs a new website or website modification.

## Discovery

- [ ] Schedule discovery meeting (Cal.com)
- [ ] Record meeting (ops.c2moviez.com)
- [ ] Define scope: new build vs modification
- [ ] Identify pages & features needed
- [ ] Collect brand assets (logo, colors, fonts, images)
- [ ] Review existing site (if modification)
- [ ] Define tech stack (Next.js, static, CMS, etc.)
- [ ] Estimate hours & create offer

## Design Phase

- [ ] Wireframes / layout mockups
- [ ] Design review with client
- [ ] Graphic assets from [[04 - Team/Besim|Besim]] if needed
- [ ] Motion elements from [[04 - Team/Silas Wirth|Silas]] if needed
- [ ] Client approval on design

## Development

- [ ] Set up repository & hosting
- [ ] Build pages per approved design
- [ ] Responsive design (mobile, tablet, desktop)
- [ ] SEO basics (meta tags, sitemap, robots.txt)
- [ ] Performance optimization
- [ ] Contact form / integrations
- [ ] Internal QA & cross-browser testing

## Launch

- [ ] Client review on staging
- [ ] Revisions
- [ ] DNS setup & domain configuration
- [ ] SSL certificate
- [ ] Go live
- [ ] Post-launch check (24h monitoring)
- [ ] Apply [[06 - Processes/Delivery Checklist|Delivery Checklist]]

## Handoff

- [ ] Documentation: login credentials, CMS guide, hosting info
- [ ] Train client on content updates (if CMS)
- [ ] Define support terms (included hours, response time)
- [ ] Close Plane.so tickets
