# Service Onboarding: Content Creation & Videography

## When to Use
Client has signed off on a content creation / videography package.

## Pre-Production (Week 1-2)

### Creative Planning
- [ ] Receive signed offer & brief from client
- [ ] Create Plane.so project with modules
- [ ] Schedule kickoff meeting (Cal.com)
- [ ] Record kickoff meeting (ops.c2moviez.com → Whisper transcription)
- [ ] Define visual style & moodboard with client
- [ ] Create shot list per theme/location
- [ ] Assign: CTI (video), [[04 - Team/Besim|Besim]] (graphics), [[04 - Team/Silas Wirth|Silas]] (motion)

### Logistics
- [ ] Location scouting & access coordination
- [ ] Equipment planning: camera, lighting, lenses, grip, FPV drone
- [ ] Schedule shoot days with client
- [ ] Book external talent if needed
- [ ] Create Plane.so sprint cycle for production phase

### Client Setup
- [ ] Frame.io folder setup: `[CLIENT] / [YEAR]-[Project-Name]`
- [ ] Share access with client for review
- [ ] Confirm deliverable format & specs

## Production (Shoot Days)

- [ ] Execute shoots per shot list
- [ ] Log footage on-set (card numbers, scene labels)
- [ ] Backup raw files immediately (dual backup)
- [ ] Store raw files in: `[NAS/Drive]/[Client]/[Project]/RAW/`
- [ ] Update Plane.so tickets per shoot day
- [ ] Start time tracking in ExeoFlow

## Post-Production

- [ ] Ingest footage → DaVinci Resolve / Premiere Pro project
- [ ] Rough cut → internal review (CTI)
- [ ] Motion graphics / text animations ([[04 - Team/Silas Wirth|Silas]])
- [ ] Color grading & sound design
- [ ] Upload to Frame.io for client review (Round 1)
- [ ] Client feedback → revisions
- [ ] Final approval → export deliverables
- [ ] Apply [[06 - Processes/Delivery Checklist|Delivery Checklist]]

## Handoff
- [ ] Final files delivered to client
- [ ] Social assets handed to [[04 - Team/Fanny|Fanny]] (if social package included)
- [ ] Time tracked & invoice created in ExeoFlow
- [ ] Close Plane.so tickets
- [ ] Archive project
