# Service Onboarding: Google Ads

## When to Use
Client has signed off on Google Ads package (Setup + Creation + Management).

## Phase 1: Account Setup (POS 01 - CHF 600)

- [ ] Create or access client's Google Ads account
- [ ] Set up billing with client's payment method
- [ ] Install Google Tag on client website
- [ ] Set up conversion tracking (forms, calls, purchases)
- [ ] Link Google Analytics 4
- [ ] Link Google Search Console
- [ ] Create Plane.so tickets for setup phase

## Phase 2: Campaign Creation (POS 02 - CHF 1'000)

- [ ] Keyword research (search volume, competition, CPC)
- [ ] Define campaign structure (campaigns → ad groups → keywords)
- [ ] Write ad copy (headlines, descriptions, sitelinks)
- [ ] Set up audience targeting
- [ ] Define bidding strategy with client
- [ ] Set daily/monthly budget caps
- [ ] Create landing page recommendations
- [ ] Client approval on campaign structure

## Phase 3: Management (POS 03 - CHF 2'400/mo)

### Weekly
- [ ] Monitor campaign performance
- [ ] Adjust bids & budgets
- [ ] Add negative keywords
- [ ] Test new ad variations
- [ ] Check search term reports

### Monthly
- [ ] Performance report to client
- [ ] KPIs: impressions, clicks, CTR, CPC, conversions, ROAS
- [ ] Budget utilization review
- [ ] Strategy call with client if needed
- [ ] Update Plane.so tickets

### Quarterly
- [ ] Full account audit
- [ ] Strategy review & pivot recommendations
- [ ] New campaign opportunities

## Team
- **Lead:** CTI (setup & strategy)
