# Campaign Workflow SOP

## Overview
Standard workflow for campaigns (2-month, 6-month, yearly contracts).

## Phases

### 1. Pre-Production
- [ ] Creative brief finalized with client
- [ ] Shot list / content plan created
- [ ] Team assigned and briefed
  - Video: Raphael (CEO)
  - Social: [[04 - Team/Fanny|Fanny]]
  - Design: [[04 - Team/Besim|Besim]]
  - Motion: [[04 - Team/Silas Wirth|Silas]]
- [ ] Plane.so sprint/cycle created
- [ ] Equipment & location booked

### 2. Production
- [ ] Shoot / record content
- [ ] Log footage and assets
- [ ] Store raw files (location: TBD)
- [ ] Update Plane.so tickets

### 3. Post-Production
- [ ] Edit video / content
- [ ] Motion graphics by Silas
- [ ] Graphics by Besim
- [ ] Internal review
- [ ] Client review round 1
- [ ] Revisions
- [ ] Client approval

### 4. Delivery & Distribution
- [ ] Export final deliverables
- [ ] Deliver to client
- [ ] Social media scheduling (Fanny)
- [ ] Archive project assets

### 5. Wrap-Up
- [ ] Final invoice via ExeoFlow
- [ ] Close Plane.so project/tickets
- [ ] Debrief meeting (record in ops.c2moviez.com)
- [ ] Move project note to `08 - Archive/`
- [ ] Update client note with project outcome
- [ ] Ask for referral / testimonial
