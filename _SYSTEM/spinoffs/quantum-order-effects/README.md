# quantum-order-effects

A zero-dependency JavaScript implementation of quantum-cognition question-order
effects, in the style of Wang & Busemeyer's quantum question-order model — plus a
two-sided falsification benchmark that is designed so the quantum model can lose.

Classical Bayesian updating is commutative: evidence E1 then E2 gives the same
posterior as E2 then E1. Human judgment is not. Asking "Is Clinton honest?" before
"Is Gore honest?" moves the answers compared with the reverse order (Gallup, Sept
1997). Quantum probability theory models this by treating each question as a
projector on a Hilbert space: non-commuting projectors produce order effects, and
the theory makes a sharp, parameter-free prediction — the **QQ equality** — that
holds for every quantum model regardless of state or measurement angles.

## Contents

- `quantum-hypothesis-tracker.mjs` — the engine. Real-valued Hilbert-space
  hypothesis tracking: state vectors, rank-1 and diagonal projectors, sequential
  measurement with renormalization, hypothesis posteriors, the QQ-equality
  statistic, Schmidt decomposition (with a hand-rolled one-sided Jacobi SVD) as a
  coupling/entanglement test, and a classical Bayes baseline for comparison.
- `quantum-vs-bayes-benchmark.mjs` — the falsification gate (see below).
- `quantum-hypothesis-tracker.test.mjs` — five deterministic tests, including the
  reduction theorem (commuting projectors reproduce Bayes exactly) and the QQ
  invariant.

No npm dependencies. Requires Node.js >= 18 (for the built-in `node:test` runner).

## Quick start

```sh
node quantum-hypothesis-tracker.test.mjs   # run the test suite
node quantum-vs-bayes-benchmark.mjs        # run the falsification benchmark
```

## The honesty gate

A benchmark that can only be passed is marketing. This one has two-sided gates,
so the quantum model can fail in both directions:

- **G1 — machinery.** On synthetic data generated by the quantum model itself,
  the fitter must recover it (RMS < 1e-3) and the joint tables must satisfy QQ
  exactly (< 1e-10), cross-checked through the tracker's own `qqEquality`.
- **G2 — real data, and it must win.** On the Gallup Clinton/Gore order-effect
  data, the observed |QQ| ≈ 0 must be non-coincidental: sweeping the full family
  of classical order-effect models that reproduce the observed marginals (Fréchet
  bounds on the free cells), fewer than 5% may land within the observed |QQ| by
  chance. The quantum model predicts QQ = 0 a priori; for a classical model it is
  a fluke.
- **G3 — control, and it must NOT win.** On synthetic order-free data, the
  quantum fit must not beat the classical static model by more than 0.005 RMS. A
  model that "wins" everywhere wins nowhere.
- **G4 — QQ residual.** The QQ residual on the real joint table must be < 0.05.

Data caveat, stated plainly: the Clinton/Gore *marginals* (Moore 2002; Gallup
Sept 6–7 1997: Clinton 50%→57%, Gore 68%→60%) are robustly attested. The *joint*
cell proportions are literature-recalled from Wang & Busemeyer 2013 and Wang et
al. 2014 (PNAS) — verify the exact cells against the primary sources before
citing them. The marginals alone carry G2.

Two structural findings are recorded in the benchmark output rather than hidden:
a pure-state 2D fit to marginals over-determines the angles and fails (strawman,
not a gate), and any 2D quantum model forces p(yy)/p(yn) = p(nn)/p(ny) per order,
which this data violates — so quantitative joint fits need higher-dimensional
models, and the 2D theory's testable content is QQ itself.

## Scope and tradeoffs

- Real-valued Hilbert space ℝ^N only — no complex amplitudes. Phases are 0 or π
  (sign flips). Sufficient for real-valued hypothesis and evidence projectors;
  full quantum interference models need ℂ^N.
- This is a cognition model, not a physics claim: projectors are a compact way to
  express incompatible measurements, following the quantum-cognition literature.
