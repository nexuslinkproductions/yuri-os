# YURI Neuroscience Corpus

Translates how brains learn/adapt into YURI's digital memory + learning store. Each entry: the biology, the digital mapping (the shared mechanism), whether it is a load-up KEY principle, and a source. The ≤8 load-up principles live in `_SYSTEM/neuro-core.md`; this corpus is the indexed detail behind them.

## 1. Mechanism catalog (28 entries)

### Systems consolidation
- **NEU-CONS-01 · Complementary Learning Systems (dual-rate)** [KEY] — Fast sparse pattern-separated hippocampus + slow distributed neocortex; two rates exist to avoid catastrophic interference. → *Digital:* fast append-only episodic buffer distilled into a slow semantic store via interleaved replay, never direct overwrite. ([src](https://pubmed.ncbi.nlm.nih.gov/7624455/))
- **NEU-CONS-02 · Sharp-wave ripples / time-compressed selective replay** [KEY] — CA3-CA1 110-200Hz offline events replay waking sequences ~10× compressed, prioritized by salience; replay duration is causally tied to retention. → *Digital:* offline consolidation pass replays recent episodes in compressed (summary/triple) form, salience-prioritized, never during live work. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC4648295/))
- **NEU-CONS-03 · SO-spindle-ripple coupling (phase-locked write window)** — Nested NREM oscillations gate a window where hippocampal output meets cortical receptivity; coupling quality predicts consolidation; TMR cues steer reactivation. → *Digital:* run consolidation only in low-contention windows; cue-triggered re-promotion when owner re-touches a topic. ([src](https://www.cell.com/trends/cognitive-sciences/fulltext/S1364-6613(24)00029-9))
- **NEU-CONS-04 · Engram cells: storage vs retrieval separable (silent engrams)** [KEY] — Trace persists under amnesia but is unretrievable by normal cues, recoverable by direct stimulation; persistence tracks connectivity, not strength. → *Digital:* separate durable RECORD from RETRIEVAL INDEX; on "forget" down-weight triggers (reversible) not delete; crosslinks = connectivity; reindex = rescue. ([src](https://pubmed.ncbi.nlm.nih.gov/26335640/))
- **NEU-CONS-05 · Excitability-gated co-allocation (time-windowed linking)** — High-excitability neurons win allocation; events within ~6h co-allocate to overlapping ensembles, physically linking them; failure mode = false linking. → *Digital:* auto-crosslink new memories active in the same bounded window; bound the window to avoid spurious binding. ([src](https://www.science.org/doi/abs/10.1126/science.aaf0594))
- **NEU-CONS-06 · Schema-assisted one-shot consolidation** [KEY] — Info matching a cortical schema becomes hippocampus-independent within ~48h after one trial; congruency gates speed. → *Digital:* score new episodes for congruency to existing clusters; HIGH = fast one-pass merge; LOW/novel = hold in buffer for more evidence. ([src](https://www.science.org/doi/10.1126/science.1205274))

### Synaptic plasticity
- **NEU-PLAS-01 · Hebbian/NMDA coincidence gate (LTP/LTD)** [KEY] — NMDA-R AND-gate passes Ca²⁺ only on pre AND post activity; large=strengthen, small=weaken. → *Digital:* strengthen a crosslink only on graded co-activation; high=strengthen, modest=prune. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC3562207/))
- **NEU-PLAS-02 · STDP — timing asymmetry encodes causality** [KEY] — Pre-before-post=LTP, post-before-pre=LTD; magnitude decays with |Δt|. → *Digital:* store retrieval ORDER not just co-occurrence; A-then-B strengthens directed edge A→B (predictive sequence memory); window=session/recency. ([src](https://www.jneurosci.org/content/20/23/8812))
- **NEU-PLAS-03 · Synaptic tagging & capture (weak rescued by strong)** [KEY] — A transient ~1-2h tag lets weak synapses capture proteins synthesized by a nearby strong event, converting early→late LTP. → *Digital:* new low-importance memories enter a tagged probationary state with a decay timer; a nearby high-salience event releases shared consolidation budget that tagged neighbors capture. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC11343274/))
- **NEU-PLAS-04 · Three-factor / eligibility-trace plasticity** [KEY] — Pre×post sets a decaying eligibility flag (~s); commits only if a neuromodulator (DA reward, NE/ACh novelty) arrives in-window. Solves delayed credit assignment. → *Digital:* on co-activation set a decaying eligibility flag; commit/scale only if reward/correction/novelty arrives in-window; one global scalar re-weights all eligible items. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC6079224/))
- **NEU-PLAS-05 · Metaplasticity / BCM sliding threshold** — The LTP/LTD threshold slides with recent activity; active units get harder to potentiate, quiet units primed. Anti-runaway. → *Digital:* track per-item activation history; slide its strengthening threshold so heavily-reinforced items get diminishing returns, rare-but-relevant potentiate fast. ([src](https://www.nature.com/articles/nrn2356))
- **NEU-PLAS-06 · Homeostatic synaptic scaling (global normalization)** [KEY] — Neurons multiplicatively scale ALL synapses toward a set-point; relative pattern (the info) preserved, gain renormalized. → *Digital:* periodically multiplicatively renormalize edge-mass to a set-point (never additive zeroing); relative rankings survive, inflation from constant reinforcement bleeds off. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC2834419/))

### Forgetting & reconsolidation
- **NEU-FORG-01 · Power-law forgetting curve** [KEY] — Retention drops steeply then flattens (power-law, not linear); ~24h consolidation bump. → *Digital:* R=(1+factor·Δt/S)^decay from last-reinforced, not a flat TTL; old-but-stable survives, never-reinforced fades fast. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC4492928/))
- **NEU-FORG-02 · Interference > decay** [KEY] — Most forgetting is retrieval competition, not passive fade; reducing competition recovers the memory. → *Digital:* treat "lost" as a retrieval/indexing problem first (fix cues/keys/embeddings) before assuming data loss; dedup near-duplicates. ([src](https://en.wikipedia.org/wiki/Interference_theory))
- **NEU-FORG-03 · Spacing + testing effect** [KEY] — Distributed recall-based reinforcement beats massed re-reading; gain largest when recall happens just before forgetting. → *Digital:* resurface when predicted retrievability nears target (~0.9), not fixed cadence; bump stability on confirmed use (expanding intervals). ([src](https://www.yorku.ca/ncepeda/publications/CPVWR2006.html))
- **NEU-FORG-04 · Active dopamine-gated forgetting** [KEY] — Forgetting is an engineered program (DA→Rac1→Cofilin); knockdown ~doubles retention. The brain spends energy to forget. → *Digital:* explicit pruner demotes/archives low-stability/low-utility/high-redundancy items on a controlled, salience-gated schedule with a TUNABLE forgetting-rate knob. ([src](https://pubmed.ncbi.nlm.nih.gov/27263975/))
- **NEU-FORG-05 · Reconsolidation — recall is a gated write window** [KEY] — Retrieval returns a memory to a labile state; rewrite only on prediction-error/mismatch; too much new info → separate new learning. → *Digital:* retrieval is a WRITE gated by mismatch: none→bump stability; contradiction→merge+re-timestamp in place; unrelated→new item. ([src](https://www.nature.com/articles/35021052))
- **NEU-FORG-06 · Force-keep protected class** [KEY] — Old/strong/salient memories resist the labile state and the active-forgetting machinery; a built-in protected tier. → *Digital:* pinned/force-keep tier (owner-locked facts, IP, identity, canonical decisions) that decay scorer, pruner, and silent-rewrite all skip; modify only with strong evidence + approval. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC5395559/))

### Salience, prediction & gating
- **NEU-SAL-01 · Dopamine reward-prediction-error (RPE)** [KEY] — Phasic DA encodes signed (actual−expected) value, transfers to earliest predictor (TD), fires AFTER outcome. → *Digital:* write a SIGNED error (outcome−expectation) at a boundary, gate plasticity by sign+magnitude; worse-than-expected up-weights, fully-expected ~zero. Keep the negative branch. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC5549862/))
- **NEU-SAL-02 · Two-component DA: fast salience then slow value** — Early ~100ms unselective salience/novelty burst, then ~200ms refined signed RPE. → *Digital:* cheap-fast force-keep detector first, expensive surprise+confidence valuation second (cost-driven split). ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC5549862/))
- **NEU-SAL-03 · Hippocampal novelty + HC-VTA loop** [KEY] — CA1 compares predicted vs actual; mismatch→novelty→DA back to HC converts early→late LTP; polysynaptic latency tags recently-active synapses. → *Digital:* compare(ΔU)→valuate(escalate)→persist(promote) pipeline with a consolidation latency; fire on PostToolUse, defer durable write to a consolidation pass. ([src](https://www.cell.com/neuron/fulltext/S0896-6273(05)00397-1))
- **NEU-SAL-04 · Novelty/reward-tagged windowed persistence** — A nearby novel/rewarding event rescues co-occurring weak memories within a minutes-hour window. → *Digital:* write cheap working-tier tags at each boundary; on a high-surprise event durably promote temporally-adjacent tagged neighbors (windowed credit assignment). ([src](https://www.nature.com/articles/nature19325))
- **NEU-SAL-05 · LC-NE adaptive gain: phasic vs tonic** [KEY] — Phasic NE raises gain on task-relevant signal (exploit); tonic NE broadens/disengages (explore), signals uncertainty → reset. → *Digital:* global gain scalar — phasic=focused high-gain depth mode; tonic=breadth/reset on context shift. ([src](https://www.annualreviews.org/doi/pdf/10.1146/annurev.neuro.28.061604.135709))
- **NEU-SAL-06 · ACh=expected vs NE=unexpected uncertainty** — ACh signals known cue-unreliability (trust fresh evidence); NE signals regime change (large revision/reset). → *Digital:* two thresholds — steady within-context update rate (believe fresh tool-results over stale expectations) + sharp reset on |ΔU| spike. ([src](https://www.cell.com/neuron/fulltext/S0896-6273(05)00362-4))
- **NEU-SAL-07 · Predictive coding — store the residual** [KEY] — Cortex predicts its input; only the error residual propagates up; predictable input is explained away. → *Digital:* don't store what the model predicts — persist only the surprising delta + a pointer to the predicting context. Episodic memory = diffs against expectation. ([src](https://www.nature.com/articles/nn0199_79))
- **NEU-SAL-08 · Precision-weighting of prediction error** [KEY] — Each error × its precision (inverse variance/confidence); high-precision errors drive updates, noisy ones damped. Precision IS attention + adaptive learning rate. → *Digital:* `write_strength = |ΔU| · precision`, precision=evidence-grade (high for deterministic local evidence, low for unverified model text). Don't burn durable memory on confidently-wrong surprises. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC4235126/))
- **NEU-SAL-09 · Bayesian surprise = KL(posterior‖prior)** [KEY] — Surprise = size of the belief update, not raw signal size; random noise is max Shannon-info but min surprise. → *Digital:* gate encoding on belief-shift; REJECT high-entropy-but-uninformative churn (white-snow guardrail); threshold in belief-shift units, not raw ΔU. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC2782645/))
- **NEU-SAL-10 · Free-energy principle / active inference** [KEY, framing] — Persisting systems minimize long-run surprise via perception (update model) + action (make inputs match predictions). → *Digital:* one scalar objective derives gating/encoding/consolidation/exploration; "escalate-for-determinism-when-uncertain" = information-seeking action. (Partly contested — adopt the behavior, not the universality claim.) ([src](https://www.fil.ion.ucl.ac.uk/~karl/The%20free-energy%20principle%20-%20a%20rough%20guide%20to%20the%20brain.pdf))

### Working memory & control
- **NEU-WM-01 · PFC working memory + basal-ganglia gating (PBWM)** [KEY] — PFC maintains task items in updatable stripes; BG provides learned RL input/output gating; capacity ~3-4 chunks, extended by chunking. → *Digital:* context window IS the WM buffer — put a LEARNED input gate (relevance×recency×task-fit×cost) + output gate in front; chunk via named handles. ([src](https://cseweb.ucsd.edu//~gary/PAPER-SUGGESTIONS/OReillyFrank06_pbwm-neural-comp-2006.pdf))
- **NEU-WM-02 · Global Neuronal Workspace — ignition + broadcast** [KEY] — Content becomes globally available only by crossing an all-or-none ignition threshold (~200-300ms), then broadcast across a frontoparietal hub; ~one ignited content at a time. → *Digital:* large cheap indexed latent corpus vs small serial always-loaded CORE; promotion = threshold-gated ignition; broadcast shared state to every lane; keep core scarce so promotion is competitive. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC8770991/))
- **NEU-WM-03 · Activity-silent / synaptic working memory** [KEY] — Unattended items drop from sustained firing to a cheap latent synaptic store, recoverable by a non-specific ping. → *Digital:* two states — ACTIVE (in context, expensive) vs LATENT (indexed, warm); demote unattended, re-summon with a targeted retrieval ping. ([src](https://pmc.ncbi.nlm.nih.gov/articles/PMC10158524/))
- **NEU-WM-04 · Metacognition / confidence as second-order readout** [KEY] — aPFC computes confidence about first-order decisions post-choice; confidence dissociates from accuracy (fluency≠correctness). → *Digital:* explicit externalized second-order check separate from the answer, allowed to LOWER confidence and trigger rework; every claim carries confidence+provenance; calibration log = digital meta-d'. ([src](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6238228/))
- **NEU-WM-05 · Attention Schema — compressed self-model of attention** — A deliberately lossy model of one's own attentional state makes top-down control stable, predictive, trainable. → *Digital:* maintain a small structured manifest of what's attended NOW (task, constraints, what's loaded, phase) — lossy by design; the controller reads it each turn (brain block / bankai manifest). ([src](https://www.pnas.org/doi/10.1073/pnas.2102421118))
- **NEU-WM-06 · Default-Mode Network — rest-state self-model** — Self-referential/autobiographical processing active at REST, anticorrelated with task; supports self-projection across time. → *Digital:* maintain identity/persona/continuity OFF the hot path, refreshed at idle/closeout (SOUL.md, MEMORY.md, EOT consolidation). ([src](https://www.pnas.org/doi/10.1073/pnas.0800376105))

## 2. How a memory moves through the system (end-to-end)
- **Encode (boundary, PostToolUse):** compute ΔU = expected vs actual mismatch. Cheap force-keep detector first (fast salience), expensive valuation second (surprise × precision). Write a cheap working-tier tag. (SAL-01/02/03, PLAS-03)
- **Link (write-time):** auto-crosslink to items active in the same bounded session window (co-allocation), directionality from recall order (STDP A→B). Bound the window — too wide = false linking. (CONS-05, PLAS-02)
- **Eligibility (post-encode):** the link is *eligible*, not committed. A later reward / owner-correction / novelty spike commits and scales it; else it decays. (PLAS-04)
- **Consolidate (offline, idle/EOT — never mid-task):** replay recent episodes COMPRESSED, salience-PRIORITIZED, INTERLEAVED with a sample of existing semantic entries. Score congruency: congruent→fast merge; novel→hold for evidence. Cue-driven re-promotion when owner re-touches a topic. (CONS-02/03/06, SAL-04)
- **Retrieve:** "lost" is a retrieval problem first — fix cues/keys/embeddings before assuming loss; a stale-index entry is a silent engram, recoverable by reindex. (FORG-02, CONS-04)
- **Update-on-recall:** mismatch gates the rewrite; confirm-and-strengthen on agreement. (FORG-05)
- **Decay + prune:** retention = (1+factor·Δt/S)^decay; resurface near target retrievability; bump stability on confirmed use; explicit tunable pruner demotes redundant/low-value items; force-keep tier skipped. (FORG-01/03/04/06)
- **Stabilize (slow global loop):** periodic multiplicative renormalization to a set-point + per-item sliding threshold so hot items get harder to inflate. (PLAS-06/05)

## 5. Honest note — solid vs aspirational
**Solid, directly portable:** precision-weighted gate (`write_strength = |ΔU|·precision`, = YURI's evidence contract restated; eligibility-trace math proven in RL); storage≠retrieval / silent engrams (down-weight triggers, never delete; reindex=rescue); two-store + interleaved-replay anti-interference (mirrors Track A/B); predictive-coding "store the residual"; Bayesian-surprise gating with white-snow guardrail; reconsolidation-as-gated-write; power-law decay (FSRS is the working proof); GNW small-core/broadcast split.
**Aspirational / framing-only:** the Free-Energy Principle is a contested, partly-unfalsifiable umbrella — adopt the objective + explore/exploit logic, not the universality claim (YURI has a hand-built energy function, not a learned generative model). ACh/NE uncertainty signalling is itself a model; YURI's side doesn't exist yet. Attention-Schema → subjective-awareness leap is out of scope; only the control-engineering benefit transfers.
**Biggest fidelity gap:** YURI's `|ΔU|` is absolute magnitude + value; dopamine RPE is signed + reward-relative — represent the negative branch (predicted-but-absent / contradiction) as a distinct down-weight, don't collapse it into "big = keep." Timescales are reinterpreted (ms→session): a deliberate functional port, sound for behavior, unsound if cited as biological evidence.
