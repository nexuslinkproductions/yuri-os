# Agent Routing

## Default Route

- Documentation, rituals, rules: Codex local edit.
- Experiments and failure analysis: Codex with tests when executable.
- Trading-bot runtime changes: Codex with GitNexus impact first.
- UI visibility: Codex plus browser/screenshot check when the frontend runs.
- Cross-domain lesson work: use canonical tags from `02_EXTRACT/cross-reference-taxonomy.md`.

## Escalation

- High-risk runtime or capital movement: require approval gate and kill switch visible.
- Unclear lesson source: convert into questions, not assertions.
- Repeated failure: rewrite into `02_EXTRACT/prevention-rules.md`.

## Handoff Payload

Every agent handoff should include:

- Current file path.
- Intended rule or experiment.
- Evidence source.
- Risk level.
- Next validation command.
