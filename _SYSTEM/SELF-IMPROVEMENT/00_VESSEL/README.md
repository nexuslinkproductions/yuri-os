## Philosophy

These are not reference documents — they're **enforcement mechanisms**. Every file here encodes a decision pattern that should be *run* before action, not just *read* for context.

### Three Truths

1. **Folders are architecture, not categories.** A naming convention enforces a thought process. The sequence of directories is the process.
2. **Memory = file system.** Externalize everything. Your brain is for processing, not for holding state.
3. **Systems over goals.** Goals are static targets. Systems are living processes.

### How to Use

1. Read `icm-methodology.md` first — understand the 3-layer architecture
2. Use `decision-matrix.md` before any significant action — is this Agent, Coworker, or Never?
3. The output of any decision becomes input to the next directory (`01_RHYTHM`)
