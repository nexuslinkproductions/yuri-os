# Weekly Consolidation — Sunday Night Ritual

> *15 minutes. No exceptions. The week doesn't count until it's processed.*

## Setup

- Time: Sunday, 21:00–21:15 (during the work block)
- Tool: terminal + the entries directory
- State: relaxed, not rushing — this is maintenance, not work

---

## Step 1 — Scan the Week's Lessons (3 min)

```bash
ls -t _SYSTEM/SELF-IMPROVEMENT/02_EXTRACT/entries/
```

Read each one. Don't analyze yet — just scan. Let the week's shape emerge.

**Check:** Did the week produce at least one lesson? If not, that's a lesson in itself — file it.

## Step 2 — Pattern Detection (5 min)

Ask: **What theme runs through these lessons?**

Common patterns:
- Same mistake in different contexts (e.g., "underestimated setup time" in both video and trading)
- Same emotional tag repeatedly (e.g., 3 "frustrated" entries = something structural)
- A skill being developed (e.g., each lesson relates to exposure metering)
- A blind spot being revealed (e.g., consistently skipping the preparation phase)

**If a pattern is found:** Write it as a 1-sentence observation in `domain-index.md` under the relevant domain.

## Step 3 — One Skill to Practice Next Week (2 min)

Pick one thing. Not a goal, not a resolution — a specific skill that surfaced in this week's lessons.

Write it down somewhere visible (notebook, sticky note, file header for next week).

> Format: "Next week I will practice [specific skill] by [specific action]."

## Step 4 — Archive Processed Lessons (2 min)

Create a weekly digest entry:

```markdown
# 2026-W[XX]-consolidation.md

**Week's shape:** (1 sentence)
**Patterns found:** (1-2 bullet points)
**Skill to practice:** (the one thing)
**Next week's intention:** (3 min, step 5)
```

Save to: `_SYSTEM/SELF-IMPROVEMENT/02_EXTRACT/consolidations/`

The individual lesson files stay in entries/ — never delete them.

## Step 5 — Write Next Week's Intention (3 min)

One sentence. What kind of week do you want?

Not "I will achieve X." More like:
- "A week of precision — tighter preparation, cleaner execution."
- "A week of listening — fewer assumptions, more questions."
- "A week of finishing — close what's open before opening something new."

The intention is a flavor, not a goal.
