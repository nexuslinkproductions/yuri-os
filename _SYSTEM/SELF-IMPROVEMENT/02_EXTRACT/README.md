## Core Rules

1. **Every project closes with a lesson.** No project is complete until at least one lesson is filed.
2. **Lessons are atomic.** One insight per file. Essays are noise.
3. **The 5-minute extraction rule.** If extraction > 5 min, the template is wrong. If > 10 min, you're journaling, not learning.
4. **The pain-first rule.** Process failures before successes. Failures contain more information per minute.
5. **Cross-reference everything.** A lesson that can't be found didn't happen.

## When to Extract

| Trigger | Timing |
|---------|--------|
| End of project/engagement | Immediately before closing |
| Major mistake or failure | Within 24 hours |
| Unexpected success | Within 48 hours |
| Weekly consolidation | Sunday evening, 15 min |
