# 02_EXTRACT — Ten (Twist)

> *Where learning happens from failures, surprises, and the unexpected.*

## Narrative Role

**Ten (転) — Twist/Insight.** This is where the story changes. Failure becomes data. Surprise becomes learning. The unexpected reveals what the plan missed.

## What Lives Here

| File | Function |
|------|----------|
| `failure-log.md` | Safe failure container — root cause analysis |
| `extraction-template.md` | 5-minute lesson extraction template |
| `domain-index.md` | Living index by domain |
| `weekly-consolidation.md` | Sunday night consolidation ritual |
| `entries/` | One file per lesson (populated by use) |

## Core Rules

1. **Every project closes with a lesson.** No project is complete until at least one lesson is filed.
2. **Lessons are atomic.** One insight per file. Essays are noise.
3. **The 5-minute extraction rule.** If extraction > 5 min, the template is wrong. If > 10 min, you're journaling, not learning.
4. **The pain-first rule.** Process failures before successes. Failures contain more information per minute.
5. **Cross-reference everything.** A lesson that can't be found didn't happen.

## When to Extract

| Trigger | Timing |
|---------|--------|
| End of project/engagement | Immediately before closing |
| Major mistake or failure | Within 24 hours |
| Unexpected success | Within 48 hours |
| Weekly consolidation | Sunday evening, 15 min |

## Context for Agents

When asked about:
- **Failures or mistakes** → read `failure-log.md`
- **Extracting lessons** → read `extraction-template.md`
- **Weekly patterns** → read `weekly-consolidation.md`, then scan `entries/`
- **What's been learned in a domain** → read `domain-index.md`
