# Morning Review Protocol — 11:00-15:00

> The admin block. Not a work block.
> Don't mistake activity for output.

---

## Purpose

This block is for:
- Syncing with the waking world
- Clearing inbound signals (messages, calendar, requests)
- Setting up tonight's work
- Handling anything that doesn't require creative depth

This block is **not** for:
- Starting new creative work
- Editing video, writing code, color grading
- Making high-stakes creative decisions

## What to Check (in order, 15 min total)

### 1. Messages (5 min)
- iMessage / SMS — personal urgency only
- Slack / Discord — client and project channels
- Signal / Telegram — if used for active projects
- Email — inbox zero approach: reply or archive, don't linger

**Rule:** If a reply takes >2 min to write, it goes into tonight's task list. Don't draft long responses in the admin block.

### 2. Calendar (2 min)
- Any meetings or calls today? (aim for none during night block)
- Any deadlines moved? Shifts to accommodate?
- Check tomorrow's first 2 events

### 3. Last Night's Log (3 min)
- Re-read the session close from `evening-reflection.md`
- Did I hit what I planned?
- If blocked: can I unblock it with an email/text/request during this block?
  - *"Need client to approve grade still" → send a follow-up now*
  - *"Asset pack didn't download" → kick off download now*

### 4. Tonight's Prep (5 min)
- What is the *one thing* that must happen tonight?
- Set a time estimate (be realistic — subtract 1h from what you think)
- If it needs a reference or tool: gather it now, put it in the project folder
- Write the first-hook sentence for tonight's kickoff
  - *"Open Premiere, go to timeline, start dialog edit on Interview B."*

---

## What NOT to Do (Hard Rules)

| Don't | Why |
|-------|-----|
| Open Premiere, Resolve, After Effects | You'll get pulled in and ruin the admin block cadence |
| Start coding | Same — you'll surface at 18:00 confused and hungry |
| Make creative decisions | Your brain is not at peak — decisions made now are worse and you'll redo them at night |
| Schedule meetings in the evening | Never let someone put a call in your night block |
| Read long emails >3 paragraphs | Save for the night block if truly relevant; 95% can be handled in 2 lines |

---

## Time Budget

| Activity | Time |
|----------|------|
| Wake + eat + prepare | 09:00-11:00 |
| Message triage | 11:00-11:15 |
| Calendar scan | 11:15-11:20 |
| Night log review | 11:20-11:25 |
| Tonight's prep | 11:25-11:30 |
| **Remaining admin time** | ~3.5 hours |
| Deep work? | **No — save for 21:00** |

Use the remaining time for:
- Light admin (expenses, invoicing, scheduling)
- Email replies you deferred last night
- Client coordination (phone calls, quick syncs)
- Errands, groceries, logistics
- Learning: read, watch tutorials, research
- Project organization (file naming, folder cleanup, metadata)

---

## Evening Hard Cutoff

At 15:00 (or whatever your break start time is), **stop all work.** 
The break between admin and the night block is mandatory — you need to decompress, move your body, eat, and reset.

The "don't open your editor" rule holds until 21:00.
