# Night Block Protocol — 21:00-05:00

> The core work engine. Everything else supports this.

---

## 1. Session Kickoff (5 min)

At 21:00, do this before touching any tool:

1. **Open the night's goal doc** (or sticky note) — one sentence:
   - *"Deliver grade pass on C2MovieZ interview and block out B-roll edits."*
   - *"Finish DaVinci timeline assembly for planzerfilms spot."*
   - *"Two leetcode mediums on dynamic programming."*

2. **Check against sprint goal** — does this tonight's work advance the weekly target? If no, reconsider. If yes, proceed.

3. **Set one output measure** — what counts as success tonight:
   - *"Exported grade pass + notes for sound design"*
   - *"Comp timeline laid out, rendered proxy for tomorrow's color"*
   - *"Three DP problems solved, typed up in Obsidian"*

4. **Phone on DND + face down.** No exceptions.

5. **Open only what you need for the first task.** No email. No messages. No browser tabs.

---

## 2. Flow State Preservation

The night block is where you produce. Protect it ruthlessly.

### Rules:
- **Single-tasking only.** One project, one frame, one code module per session.
- **No notifications during deep work.** Slack, Discord, iMessage all silenced until break.
- **No browsing.** If you need a reference, bookmark it during admin block or write "lookup: [thing]" in your notes.
- **No checking phone.** It doesn't exist between 21:00 and your first break.
- **Music is allowed.** Instrumental only (synthwave, ambient, classical, lo-fi).
- **If stuck >5 minutes on a problem,** write down the blocker and switch to the designated fallback task. Don't spin.

### Flow Entry Triggers:
- Put on headphones with a specific playlist (train your brain: this music = work mode)
- Start with the easiest subtask to build momentum
- Re-read your goal sentence aloud once

### Flow Break Signals:
- Blinking excessively
- Reading the same line three times
- Irritation at minor friction
- Reaching for phone

When you notice these: break. Not optional.

---

## 3. Break Protocol

### When to Break
- Every 90 minutes minimum
- When flow breaks naturally (task completion, stuckness, fatigue)
- **Never push through** — you lose more time trying to force it

### How to Break (10-15 min)
1. Stand up. Walk away from desk.
2. No screens. No phone check.
3. Hydrate (water or tea — no caffeine past 02:00).
4. Stretch or quick walk around the apartment.
5. If possible: look at a distant point for 2 min (reduces eye strain).
6. Don't start a conversation, don't open social media.

### How to Return
1. Re-read the goal sentence from kickoff.
2. Look at last 3 lines of what you were working on.
3. Continue. No re-checking email "just to be sure."

---

## 4. Energy Dip Management

Your energy will dip around 01:00-02:00. This is normal. Have a plan:

### Fallback Tasks (keep on a sticky):
- B-roll organization (low cognitive load)
- Metadata entry / keyword tagging
- Shot notes from the day's capture
- Admin clearing (inbox cleanup, file renaming, folder structure)
- Learning: watch a DaVinci tutorial at 1.5x
- Light reading: technical docs, camera manuals, CSS reference

**Designate ONE fallback task before kicking off.** When energy dips, switch immediately. Don't burn decision energy choosing.

### Red Line (04:00):
- If you're still at the desk at 04:00 and grinding, stop.
- The last hour should be winding down — review, reflection, tomorrow's hook.
- Pulling an all-nighter breaks Wednesday's block too. One bad night → three bad nights.

---

## 5. Session Close (5 min)

At 04:00-05:00, close deliberately:

1. **Save and quit everything.** No "I'll just finish this one thing."
2. **Log tonight's output** (can be one line):
   - *"Grade pass complete on interview A. B-roll selects done for scenes 1-3."*
3. **Set tomorrow's first hook:** What is the *first* 5-minute action tomorrow night?
   - *"Open Resolve project, check grade pass on scene 4."*
   - *"Open Chrome, type first test case for DP problem 4."*
4. **Close applications.** Shut down if you won't wake for 6+ hours.
5. **Exit ritual:** Put headphones away, turn off desk light, close laptop. Physical closure matters.

### If You Didn't Hit the Goal
- Note *why* (one sentence): *"Underestimated scene 4 complexity — color match took 2x expected."*
- That's data, not failure. Account for it in tomorrow's estimate.
- **No guilt spiral.** Tomorrow is another block.
