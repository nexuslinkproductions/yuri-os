# Token Efficiency

## Compression Rules

1. Lead with action, path, or finding.
2. Drop motivational preamble.
3. Keep plans as checklists only when execution spans multiple files.
4. Keep raw research out of chat; link to files.
5. Rewrite repeated instructions into rules.

## Context Budget

| Layer | Budget |
| --- | --- |
| Chat updates | 1-2 sentences |
| Implementation notes | Path plus reason |
| Reports | Findings first |
| Rules | One sentence each |

## Failure Trigger

If a message repeats a prior instruction, promote it into a durable rule or routing note instead of repeating it again.
