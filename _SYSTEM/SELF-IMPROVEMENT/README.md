# SELF-IMPROVEMENT — A Narrative System

> *Folders are architecture, not categories. This system follows a story.*

## The Arc (Kishōtenketsu 起承転結)

Every system follows a story. This one is a four-act cycle:

```
VESSEL → RHYTHM → EXTRACT → GAZE → (back to VESSEL)
```

### 00_VESSEL — Ki (Introduction)
**Identity, core frameworks, ICM philosophy.**
*"Once upon a time, there was a way of thinking..."*
- The mental models that govern how improvement happens
- Read this first. Before you improve, know *how* you improve.
- → `00_VESSEL/`

### 01_RHYTHM — Shō (Development)
**Practices, protocols, schedules.**
*"And then, every day..."*
- The daily engine. Non-negotiable protocols.
- Execute this second. Discipline applied daily is the only source of compound growth.
- → `01_RHYTHM/`

### 02_EXTRACT — Ten (Twist/Insight)
**Learnings, extractions, failure log.**
*"But then, something unexpected happened..."*
- Where change happens. Failure becomes data. Surprise becomes learning.
- This is the part of the story that pivots.
- → `02_EXTRACT/`

### 03_GAZE — Ketsu (Resolution)
**Metrics, vision, quarterly review.**
*"And so, does the system work? Where are we going?"*
- Metric evidence. Direction. The closing loop that feeds back into the vessel.
- → `03_GAZE/`

## How to Navigate

### For Humans
1. **First time?** Start at `00_VESSEL/README.md`
2. **Establish rhythm?** Move to `01_RHYTHM/`
3. **Learning from experience?** Use `02_EXTRACT/`
4. **Checking progress?** Open `03_GAZE/`
5. **The cycle never ends** — evidence from GAZE updates the VESSEL

### For Agents
- Read `_Directory_Map.md` first (< 200 tokens) for a flat view of everything
- Read `_claude.md` for query routing — "I need X, read which file?"
- Default sequence: `_Directory_Map.md` → `00_VESSEL/icm-methodology.md` → specific query

## Why Narrative Instead of Categories

| Dimension | Before (Categories) | After (Narrative) |
|-----------|---------------------|-------------------|
| Root directories | 5 (01-05) | 4 (00-03) |
| Mental model | "Which folder does this go in?" | "Where am I in the story?" |
| Flow | Linear categories | Cyclic narrative arc |
| Memorability | Must remember 5 categories | Follow a 4-act story arc |
