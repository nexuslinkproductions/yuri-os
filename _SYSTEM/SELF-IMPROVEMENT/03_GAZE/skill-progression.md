## Levels

| Level | Description | Evidence |
|-------|-------------|----------|
| **Novice** | Can do it with guidance | Requires references, tutorials, or supervision |
| **Competent** | Can do it alone | Works independently, occasional lookup |
| **Proficient** | Can do it efficiently | Doesn't think about mechanics, focuses on outcome |
| **Expert** | Can teach it | Others come to you for answers |
| **Master** | Can innovate it | Pushing the domain forward |

```markdown
### <Skill Name>
- **Current level:** Novice
- **Estimated hours invested:** 0
- **Last milestone:** N/A
- **Next milestone:** <Define the first concrete milestone>
- **Hours toward next milestone:**
- **Notes:**
```

**Rules for adding:**
- Only add if you've invested or plan to invest 50+ hours
- Don't add skills you "might" learn — only active domains
- Maximum 7 active domains. If you add one, drop or complete one.

## Review Cadence

- **Monthly:** Update hours, levels, and milestone progress. Run on the last night block of the month during the pattern review.
- **Quarterly:** Deep assessment — is each domain still aligned with your trajectory? Drop domains that aren't moving.
- **Milestone trigger:** When you hit a milestone, update immediately (feels good, takes 30s).

## Level Change Criteria

| Transition | Typical Hours | Indicators |
|-----------|---------------|------------|
| Novice → Competent | 20-50 | Can complete work without hand-holding |
| Competent → Proficient | 100-200 | Fast, fluid, doesn't need reference material |
| Proficient → Expert | 500-1000 | Others ask for your input |
| Expert → Master | 2000+ | You're contributing new knowledge |

These are rough guides. Some domains (Japanese) take significantly longer. Judge by capability, not hours.

## Rules

- Be honest about your level. It's not a rank — it's a signal for what to practice next.
- If you haven't touched a domain in 3 months, flag it for quarterly review.
- Hours are cumulative estimates, not weekly tracked. Update once per month.
