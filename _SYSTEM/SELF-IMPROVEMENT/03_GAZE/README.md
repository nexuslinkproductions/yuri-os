## Narrative Role

## Core Philosophy

### The 3-Metric Maximum
Only three metrics matter: **OUTPUT** (did you ship?), **ENERGY** (are systems sustainable?), **GROWTH** (are you moving toward mastery?). Everything else is noise.

### Vision as Direction, Not Destination
Direction implies continuous orientation — you can adjust without having failed. The vision holds steady; the path bends.

### The Void Principle — Leave Space for Emergence
Every quarter should have ~25-30% unallocated capacity. If you fill 100%, you have zero room for the work that finds you.
