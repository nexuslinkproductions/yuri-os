# Time Allocation — Weekly Log

> One line per night. <1 min to enter. Monthly pattern review.

## Category System

| Category | Includes | Monthly Target |
|----------|----------|----------------|
| **Client Work** | client deliverables | < 50% |
| **System Building** | YURI, Yuri Flow, tooling, automation, your ecosystem | 15-25% |
| **Learning** | Japanese, trading, esoteric study | 10-20% |
| **Admin** | Email, invoices, scheduling, logistics, shopping, chores | < 10% |
| **Rest** | Sleep, gym, social (non-work), cooking, deliberate rest | > 20% |

**Hard rules:**
- If **Client Work** exceeds 50% for 2 consecutive weeks → flag for rate increase or capacity cap
- If **Admin** exceeds 15% → automate or delegate
- If **Rest** falls below 15% → cancel commitments until it recovers
- If **System Building** falls below 10% → you're eating seed corn

## Monthly Pattern Review

Run on the last night of the month. Answer:

1. **Category balance:** Is anything out of alignment? What shifted?
2. **Client concentration:** Any single client pulling too much time?
3. **Deep work ratio:** How many nights had 4+ hours of uninterrupted focus?
4. **Discretionary drift:** Did admin or non-essential work creep up?
5. **Adjustments for next month:** Change one thing.

## Rebalance Triggers

| Signal | Action |
|--------|--------|
| Any category > 40% for 3+ weeks | Rebalance plan required |
| Rest < 15% | Hard stop — cancel until recovered |
| Admin > 15% | Automate or delegate within 1 week |
| 2+ missed logs in a week | Simplify the tracking system |
| Client Work > 50% x 2 weeks | Check pricing or capacity |

## Notes

- Night block is primary. If you also worked during the day, append a `+1h Day` per entry.
- Round to the nearest half-hour. No precision obsession.
- If a night was split across categories, list each chunk on its own line.
- Use the weekly review to look for patterns, not to judge yourself.
