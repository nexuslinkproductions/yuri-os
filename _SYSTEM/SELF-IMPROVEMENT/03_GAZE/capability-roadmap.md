### Key Dependency Checks

1. **Trading bot needs data first.** Do not start coding signal logic until you have confirmed reliable data feed. Feed instability will waste 3x the time.
2. **RAG pipeline needs content + embeddings.** Do not build a fancy UI before you have 50+ useful sources indexed. Start with the dumbest possible version.
3. **Studio ops needs income stability.** Do not plan hires or studio space while client income is variable. Stabilize first.

## Time Reality Check

At ~140h/quarter effective:
- **Goal 1 (client stability):** ~10h — mostly conversations, proposals, agreements
- **Goal 2 (YURI maturity):** ~40h — HUD + RAG pipeline
- **Goal 3 (trading bot):** ~40h — scan → signal → compound pipeline
- **Emergence/rest:** ~60h remainder

These are rough. The quarterly review adjusts. The key constraint is not energy or skill — it's that you cannot do three 40-hour goals in one 140-hour quarter. Pick the hardest problems and let the rest flex.
