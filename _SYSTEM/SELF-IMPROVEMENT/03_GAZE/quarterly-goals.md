## Progress Check Format

**When:** Last week of each month (10 minutes max)

**Process:**
1. Open this file
2. For each goal, check status:
   - **Green** — on track, no blockers
   - **Yellow** — progress but blocked or slower than expected
   - **Red** — not happening this quarter, needs honest downgrade
3. Write one sentence in the relevant monthly check box
4. If yellow or red: write the blocking question answer in the note
5. Close the file

**Rule:** A red goal is not a failure. It's a data point. Either reprioritize for next quarter or cancel consciously.
