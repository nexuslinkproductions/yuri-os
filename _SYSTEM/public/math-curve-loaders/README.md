# Math Curve Loaders

Local reference mirror for the upstream `math-curve-loaders` project.

## What this folder is

- A dependency-free static bundle
- A lightweight local catalog for inspecting the upstream gallery's curve families
- A clear mirror, not the source of truth

## Files

- `index.html`: local landing page
- `styles.css`: layout and presentation
- `main.js`: catalog rendering and selection state
- `README.md`: local notes and source links

## Source of truth

- Upstream repo: <https://github.com/Paidax01/math-curve-loaders>
- Live preview: <https://paidax01.github.io/math-curve-loaders/>

## Usage

Open `index.html` in a browser, or browse the folder from the built app. The page is intentionally small so it can be inspected quickly inside this repo.

## Mirror notes

- This folder keeps the upstream project easy to find locally without introducing new runtime dependencies.
- The local page is a curated reference layer. If you need the full interactive gallery, use the upstream project.
