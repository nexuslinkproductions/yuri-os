# NEURAL_FORGE // AUTONOMOUS_LLM_ORCHESTRATION

## 1. MISSION_STATEMENT
To transform the NUDIMMUD Command Center into a world-class, local-first LLM development environment. The **Neural Forge** (ENKI) serves as the laboratory for the 'Oracle' core, enabling autonomous benchmarking, fine-tuning orchestration, and architectural reverse-engineering of state-of-the-art open-source models.

## 2. CORE_INTEL: GLOBAL_OS_MODEL_REGISTRY (2026_COHORT)

### A. THE_ASIAN_PHALANX (Efficiency & MoE)
- **DeepSeek V3**: Pioneer of Multi-head Latent Attention (MLA) and DeepSeekMoE.
- **Qwen 2.5/3**: Alibaba's powerhouse for coding and multilingual reasoning.
- **InternLM 2.5/3**: Advanced instruction-following and W&B integration.
- **Yi 1.5/2**: High-fidelity pre-training with massive context (200k+).

### B. THE_GOOGLE_EVALUATION (Gemma Ecosystem)
- **Gemma 3**: Latest multi-modal open-weights iteration.
- **RecurrentGemma**: Linear attention architecture for infinite context experimentation.
- **MaxText**: Google's JAX-native training framework for TPU/GPU.

## 3. BENCHMARKING_PIPELINE
We implement a local version of **OpenCompass** to evaluate:
- **MMLU / GSM8K**: General knowledge and math.
- **HumanEval**: Coding velocity.
- **IFEval**: Instruction following precision.

## 4. HUD_INTEGRATION (ENKI_MODULE)
- **Leaderboard**: Real-time comparison of global vs. local model performance.
- **Telemetry**: Live TPS (Tokens Per Second) and VRAM occupancy monitoring.
- **Forge Control**: Direct hooks for initiating fine-tuning jobs (Axolotl/Unsloth).

## 5. REVERSE_ENGINEERING_OBJECTIVES
- **MLA (Multi-head Latent Attention)**: Study DeepSeek's reduction of KV cache.
- **Hybrid-Recurrent**: Analyze Gemma's recurrent states for memory-efficient long context.
