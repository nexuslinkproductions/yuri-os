## EXECUTION INSTRUCTIONS

### Quarantine pattern (mandatory for all destructive ops)

Never `rm` or `rm -rf` directly. Always:

```bash
mkdir -p _QUARANTINE_$(date +%Y-%m-%d)/<category>/
mv <thing> _QUARANTINE_$(date +%Y-%m-%d)/<category>/
# review, then later:
rm -rf _QUARANTINE_$(date +%Y-%m-%d)/
```

This makes every cleanup reversible until the quarantine is purged.

### How to spawn a workhorse

For each independent task:

```
/spawn /deepseek-workhorse

Forbidden paths: Scripts/ bin/ Volumes/ GeneratedContent NUDIMMUD/ Claude\ Code\ URL\ Handler.app DOMAIN\ EXPANSION\ -\ INFINITE\ VOID/
```

1. Print a summary of what it will do
