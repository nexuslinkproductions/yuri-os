# Section 2: The Gap

The dynamics question from Section 1 has a precise answer: no part of the current ICM/MWP framework governs them. This is not a design oversight — it is a scope boundary. ICM and MWP solve *structural containment*. What the field has not yet formalized is *dynamical containment*: the problem of constraining how an agent system moves through its state space, not just what state space it is permitted to occupy.

The distinction matters. Structural containment answers questions about topology: which stages are defined, which resources are reachable at each stage, which credentials are in scope. These properties are static. They can be verified by inspection at rest. Dynamical containment asks a different class of question: which transitions are valid, which states are recoverable, which directions through state space represent genuine forward progress. These properties are behavioral. They cannot be verified by inspection at rest — they require a measure that applies during execution.

The absence of such a measure creates a specific class of failure that structural containment cannot prevent. An agent system can satisfy every ICM structural constraint — correct folder, correct credentials, correct scope — while its internal epistemic state moves in any direction. What makes this failure distinctive is not that it can happen, but that it is undetectable from the structural layer: two systems, one converging toward coherent verified claims and one cycling through contradictory ones, look identical from outside the stage boundary. Structural inspection cannot distinguish them.

The energy-based-models literature offers a useful analogue for the missing machinery. EBM work defines scalar potential functions over state, such that configurations become interpretable as points on an energy surface. A valid operation descends the surface; an invalid one — drift, incoherence, spurious promotion — violates a conservation property. The Potential-Derived layer concept makes this explicit: a well-formed system should admit a conservative vector field over its configuration space, ensuring that any sequence of valid transitions is path-independent and eventually terminating at a low-energy (coherent, verified) configuration.

The gap in ICM/MWP is precisely the absence of this object. A Lyapunov-style function over orchestration state — a scalar quantity that strictly decreases along any valid transition sequence — would close it. The open question is not whether such a function is mathematically available — the primitives for composing one are already defined in the literature. The question is whether they transfer faithfully to the control-plane layer, and what a working composition rule looks like in practice.
