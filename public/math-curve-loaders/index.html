Source Notes

      

        

          
What lives here

          

            A local reference mirror with a curated catalog of the upstream gallery's curve families.
            It stays lightweight on purpose so the bundle is easy to inspect in the repo.
          

        

        

          
What stays upstream

          

            The original interactive animation engine, the live preview site, and any future gallery changes remain upstream.
            Use this folder as a local lookup layer.
          

        

        

          
How to use it

          

            Open this folder directly in the built app, or browse the files in place.
            The README lists the source links and the local file map.
