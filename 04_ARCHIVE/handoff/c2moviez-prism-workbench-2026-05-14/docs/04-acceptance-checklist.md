# PRISM Acceptance Checklist

## Owner Acceptance

- [ ] PRISM opens on Today view, not a CRM dashboard.
- [ ] UI name is PRISM.
- [ ] Interface feels premium, not generic.
- [ ] Topbar always shows sent this week, overdue follow-ups, blocked leads.
- [ ] Fanny can work from Today mission without manually hunting through views.
- [ ] "Open next lead" selects the compliance-safe highest-score lead.

## Operator Loop

- [ ] Fanny can review a Dossier.
- [ ] Fanny can open Draft tab and edit generated upstream drafts.
- [ ] Draft versions are visible.
- [ ] Draft workspace shows context and personalization checklist.
- [ ] Draft language policy is English-only.
- [ ] Every draft is grounded in visible Dossier evidence.
- [ ] Drafts avoid unrelated claims, invented pain, fake familiarity, inflated promises, and broad sales pitches.
- [ ] Drafts read like concise human outreach, not AI-generated spam.
- [ ] Fanny sees what PRISM noticed, why it matters, and which claim the draft is based on.
- [ ] Thin-evidence leads are held for more research instead of producing generic drafts.
- [ ] Copying a draft opens a confirmation modal.
- [ ] Mark-sent confirmation asks for channel and follow-up date.
- [ ] After sent, PRISM asks what to do next.
- [ ] Weekly target counts 20 sent, not reviewed or touched.

## Compliance & Suppression

- [ ] Review-needed CH leads can be drafted but cannot be marked sent.
- [ ] AT email is allowed only when a public business email path is documented.
- [ ] Fanny sees simple compliance status and reason.
- [ ] Marcel/admin can inspect full compliance details.
- [ ] Opt-out creates suppression for email, LinkedIn URL, and exact contact/company identity.
- [ ] Company-wide suppression is only applied when explicitly requested.

## Source Quality

- [ ] Dossier shows source, source confidence, evidence, and fit reason.
- [ ] Wrong-lead risk is visible before drafting.
- [ ] Full source pipeline data feeds PRISM, not only static existing leads.
- [ ] Website and gathered public signals are summarized before draft generation.
- [ ] The draft generator can identify missing or weak evidence and withhold ready-to-send status.

## Admin

- [ ] Analytics are oriented to Marcel/admin.
- [ ] Admin can see source and compliance health.
- [ ] Fanny is not distracted by admin pipeline internals.

## v1.1 Candidates

- [ ] Keyboard shortcuts implemented after v1 core.
- [ ] Command palette implemented after v1 core.
- [ ] Undo layer implemented if campaign budget remains.
