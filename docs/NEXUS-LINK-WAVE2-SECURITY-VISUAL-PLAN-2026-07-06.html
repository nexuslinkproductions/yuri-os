00 · The honest why — breaches are boring, not exotic

The verified research (OWASP / NIST / CIS / MITRE + named-breach post-mortems) is unanimous: Nexus's breach risks are not zero-days, they're misconfigured boring infrastructure. Every headline breach traces to one of these. Wave 2 is the discipline that stops them — none of it is exotic hacker-art; all of it is well-vetted, open, buildable.

The meta-failure across nearly every breach

Insufficient logging & monitoring (OWASP A09). Equifax attackers were inside ~78 days; MOVEit ran weeks; LastPass had a multi-month gap. Median dwell time is 100+ days. Breaches aren't stopped at intrusion — they're stopped at detection. That's why the audit spine (L3) + the L5.5 detection layer are non-negotiable in Wave 2, not optional polish.

01 · The three load-bearing gaps Wave 0–1 left open

The L1–L6 posture drawn earlier is a labeled skeleton, not a hardened system. Three gaps are load-bearing — they close before any tenant PII lands on Hetzner.

① Network perimeter — absent

Postgres / Studio / Kong bind to all interfaces with no host firewall. On a bare Hetzner box they're internet-reachable. Highest-leverage fix: default-deny + Cloudflare-origin IP allowlist + bind 127.0.0.1.

② Audit trail — a mutable stub

Not migrated; covers only leads/contacts; mutable (compromised admin rewrites history undetected); str(e) in 500s leaks tokens; feeds no alerting. Fix: NO UPDATE/DELETE + hash-chain + denylist sanitizer + WORM export + detection.

③ Encryption — under-specified

"Encrypted at rest" is meaningless without the primitive + nonce + key hierarchy. Postgres has no native TDE; Supabase deprecates pgsodium/pgcrypto. Fix: LUKS + XChaCha20-Poly1305-IETF (192-bit nonce) + per-tenant Vault KEK.

03 · The build sequence — highest-leverage first

Not "everything at once." The order is engineered: cheapest blast-radius reduction first, breach-detection spine second, then the crypto, then the polish. Each step ends with a gate.
1
Network perimeter cheapest · highest leverage
ufw default-deny + Cloudflare-origin allowlist + bind Postgres/Studio to 127.0.0.1 + Cloudflare Tunnel for admin. Collapses the internet-reachable-DB risk in hours.
GATE · ss -tlnp shows no public DB/Studio ports · origin IP not in public DNS · allowlist freshness < 25h
2
Audit hash-chain spine
audit_log table (NO UPDATE/DELETE) + the 0x00-prefixed BEFORE-INSERT trigger + nightly verification + PII-audit triggers. Fixes str(e) token leak via the log sanitizer. This is the breach-detection spine — without it, dwell is 100+ days.
GATE · nightly verification returns all-OK · a deliberate row-tamper is detected · str(e) no longer reaches logs
3
Field-level encryption
XChaCha20-Poly1305-IETF for OAuth tokens + DM bodies. LUKS on the Hetzner host. Per-tenant keys via HKDF from the (soon-to-arrive) Vault KEK.
GATE · token ciphertext round-trips · AAD binds ciphertext to (tenant, row) · key never co-located with ciphertext
4
Envelope encryption + Vault KEK
Self-hosted Vault on Hetzner (EU sovereignty), transit engine, one transit key per tenant. DEKs transient + zeroised. DSGVO erasure via cryptographic shredding.
GATE · per-tenant wrapped_dek cannot decrypt under another tenant · DEK never persists plaintext · Vault EU-hosted
5
App-layer defense
SECURITY DEFINER public writes + psycopg3 binding + SSRF egress guard (reuses social-adapter) + the root-logger sanitizer. Fixes the public-write SQLi surface.
GATE · G1 negative test (tenant A can't touch tenant B) green in CI · no string SQL in the service
6
Supply chain + WAF block-mode
SBOM/grype in CI + SLSA L3 provenance + scoped-namespace deps + Tauri signing in isolated release env. And the WAF flips log→block after its 2-week tuning cadence.
GATE · grype fails-CI on critical CVEs · Tauri release attested + signed · WAF in block-mode with zero recurring false-positives
The one sequencing trap — WAF block-mode is a GATE, not a default

WAF in block-mode on day 1 is the most common Wave-2 outage — legitimate CRM traffic (rich-text deal notes, German umlauts, JSON with SQL-like keywords) trips OWASP CRS rules 942100/932100 and blocks paying users. Always log-mode 2 weeks → review Security Events daily → write targeted ctl:ruleRemoveTargetById=<id>;ARGS:<param> exclusions → only then flip to block. A WAF that blocks tenants is its own outage.

04 · DO NOT USE — what Wave 2 refuses to ship

These are the anti-patterns the verify pass explicitly killed. They're not preferences — each one is a documented breach vector or a cryptographic footgun.
Hand-rolled AES-GCM / random-96-bit-nonce field crypto — single nonce reuse = catastrophic (leaks auth key + plaintext XORs). Use XChaCha20-Poly1305-IETF.
bcrypt for new code — legacy-only, truncates at 72 bytes, no memory-hardness. Use Argon2id.
A linear hash chain labeled "RFC 6962" — RFC 6962 is a Merkle tree with mandatory 0x00/0x01 domain-separation prefixes. Omitting the prefix loses second-preimage resistance.
Global WAF rule removal (SecRuleRemoveById 942100) instead of parameter-scoped exclusion — re-opens the entire attack surface on every endpoint.
SMS-based 2FA — SIM-swap risk. TOTP/WebAuthn only.
PEPPER in DB / .env / repo — defeats the entire control; OWASP-forbidden.
US-region KMS for KEK unwrap — breaks DSGVO / Schrems II. Vault stays EU-hosted.
psycopg ClientCursor / mogrify — client-side merge re-enables SQLi.
Cloudflare One Access mTLS as workload identity — human/device-to-app only, not service-to-service.

06 · Residual risk + open questions

HIGH
Wave 2 is pre-customer, not post-breach. It reduces the attack surface dramatically but a determined adversary + a future CVE still get in. The audit spine + L5.5 detection + a tested G12 incident runbook (DSGVO Art. 33 72h) are the real safety net — detection + response, not just prevention.
HIGH
The Tauri binary is the SolarWinds surface. SLSA provenance + isolated release signing is what catches a build-pipeline compromise. If Wave 2 defers the Tauri signing, the desktop update channel is the soft underbelly.
MED
Supabase Auth hash algorithm. If it's bcrypt (not Argon2id), L1 needs a migration workstream. Open question — verify before relying on it.
MED
Vault vs Infisical. Both EU-self-hostable; Vault is more mature (transit engine), Infisical is lighter DX. Ops-budget call (no platform team).
LOW
WAF false-positive discipline. Bounded by the 2-week log-mode cadence — the only real risk is skipping it.
