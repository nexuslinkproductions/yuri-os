## Conventions

- One file per launch or campaign: `launch-<model-or-gun>-<YYYY-MM-DD>.md` with sections
  **Facts (sourced)** → **Woo DE** → **Woo EN** → **Etsy** (if applicable) → **LinkedIn** → **Instagram**
  → **Renders** → **needs René sign-off**.
- Copy audits: `audit-<surface>-<YYYY-MM-DD>.md` (violations of `cgs-holster-copy-rules`, with the
  live text quoted and the fix proposed).
- Every fact line names its source: `boms`, `cam/vocab`, `accessories`, the live product URL, or a
  memory handle. Unsourced = flagged, not written.
- Dates in filenames ISO; dates in copy dd/mm/yyyy.
