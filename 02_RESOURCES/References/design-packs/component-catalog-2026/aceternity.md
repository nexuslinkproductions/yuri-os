## SELECTED API SPECS

### Magnetic Button
**Deps:** framer-motion, @aceternity/magnetic-button
**Motion:** spring physics, cursor tracking
**Props:**
- `children` React.ReactNode — element to wrap with magnetic effect
- `strength` number (default 0.8) — cursor follow strength; 1 = exact match
- `maxDistance` number (default 100) — max drift distance in pixels

### 3D Card Effect
**Deps:** framer-motion, @aceternity/3d-card
**Sub-components:** CardContainer, CardBody, CardItem
**CardItem Props:** translateX, translateY, translateZ, rotateX, rotateY, rotateZ, as, children, className
