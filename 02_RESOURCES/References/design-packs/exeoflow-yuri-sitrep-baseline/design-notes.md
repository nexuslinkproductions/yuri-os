# Design Notes

## Current Archetype

Premium dark consumer briefing site with SITREP elements.

Core flow:

1. Hero story.
2. How to use.
3. Commercial path.
4. Target explorer.
5. Location SITREP map.
6. Portfolio lens.
7. Evidence board.
8. Send package.

## Visual DNA

- Nexus Link-inspired dark cinematic shell.
- Rounded glass navigation.
- Large Space Grotesk headlines.
- Outfit body copy.
- JetBrains Mono labels.
- Purple and cyan accents.
- Dark CARTO/OpenStreetMap map tiles.
- Custom numbered markers for target priority.

## Interaction Patterns

- Top navigation anchors.
- Scroll progress bar.
- Search clears filters.
- Filters clear search.
- Target cards update selected account profile.
- Leaflet map supports pan, zoom, scroll zoom, touch zoom, and marker clicks.
- Map focus buttons: all targets, Switzerland, Austria, selected.
- Evidence cards link to public source anchors.

## What Works

- The page is easier to read than the earlier HUD cluster.
- The SITREP map gives geographic context and makes Switzerland expansion visible.
- The selected target panel keeps the account narrative digestible.
- Official contact route plus action plan makes the artifact more operational.
- The product story is clearer: map one workflow, prove value, expand into YURI OS.

## Current Weaknesses

- Visual system is still basic relative to the intended “military-grade premium briefing” goal.
- Map markers cluster and need better spiderfying, clustering, or layered zoom states.
- The SITREP map is useful but not yet cinematic enough.
- There is no animated transition between selected targets.
- Account cards are functional but not emotionally memorable.
- Evidence board is flat and should become source-trace timeline / dossier stack.
- No embedded relationship path, sponsor hypothesis confidence, or next-step status.
- No data freshness model.
- No export/share mode for Claudio.
- No live source validation.

## Quality Bar For Next Version

The next version should feel like a calm high-end intelligence product, not a themed HTML report.

Target qualities:

- Clear reading path.
- Premium restraint.
- Smooth but sparse animation.
- Beautiful real map.
- Better target clustering.
- Stronger information architecture.
- Account-level mini dossiers.
- More explicit action priority.
- More source confidence metadata.
