## Design Rules Extracted

- One dominant motion system per viewport.
- Noisy background layers only when text density is low.
- Hover should reveal value, not hide required information.
- Gallery motion should frame the subject, not become the subject.
- Radial and orbital systems need obvious active states and keyboard support.
- Preference goes to calm defaults with strong active transitions.
