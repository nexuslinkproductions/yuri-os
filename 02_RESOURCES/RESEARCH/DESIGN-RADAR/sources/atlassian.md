# Atlassian

Source: https://atlassian.design/design-system/

## Signals

- Modular foundations.
- Clear content standards.
- AI-aware patterns and enterprise-level structure.

## Useful patterns

- Top-level structure that is easy to learn.
- Reusable controls with clear behavior.
- Strong content discipline.

## Apply to YURI

- Use Atlassian as the reference for a top nav and command rail.
- Clean up naming so every label reads like product UI.
- Split the OS into predictable, composable regions.
