Yuri — the "hey Yuri" super-assistant

Architecture, clicky-spined. A native macOS companion that sees your screen, understands what you're doing, and acts alongside you — voice-first, always-on, cloud-brained (GLM-5.2), local-lightweight-infra.

The edge: Yuri perceives via the Accessibility tree (structured, instant, ~80% of the time, no screenshot) and falls back to OmniParser-v2 vision only when AX sees nothing (Electron/canvas). Clicky (and Anthropic Computer Use) screenshot-first — slower, costlier, less reliable. Structured > pixel-guessing.

How Yuri acts — the perceive → think → gate → do loop

① Perceive (primary)
Accessibility tree
AXUIElement via JXA → {app, elements[], focus, text}. ~80% of cases. No screenshot.
① Perceive (fallback)
OmniParser-v2
Only when AX = ∅ (Electron/canvas). screencapture → [{bbox,caption}]. On-demand, zero VRAM resident.
② Think
GLM-5.2 brain
Reasons over the structured context. Emits ONE action (click/type/open/…).
③ Confirm-gate
PreToolUse hooks
Allowlist → silent. Denylist (delete/send/financial) → confirm. Unknown → default-deny. Outside the LLM.
④ Do + verify
osascript executor
System Events acts. Re-read AX / screen-diff to confirm. Loop or done.

■ Clicky's way (what we beat)

Screenshot-first, single Anthropic VLM. Every action: screencapture → Claude Computer Use API (computer_20251124) → pixel-counted coordinate.

per action: screenshot round-trip + full VLM inference (~3–8s)
vendor: Anthropic-locked
cost: every action bills the vision model

"sloppy and slow" — the operator's call.

■ Yuri's way (the edge)

AX-first, dual-path, model-agnostic. Reads the structured accessibility tree directly — no screenshot for ~80% of actions. Vision only when AX fails.

per action (AX): ~5–50ms (no VLM)
brain: GLM-5.2 (cloud, $0 Coding Plan)
vendor: none locked

faster, cheaper, more reliable, vendor-free.
