# Vercel / Geist

Sources:
- https://vercel.com/design
- https://vercel.com/geist/introduction

## Signals

- Clean developer tooling aesthetic.
- Sharp tokens and consistent spacing.
- Calm, premium, readable docs and product surfaces.

## Useful patterns

- Typography-led composition.
- Minimal but expressive grids.
- Strong empty and stateful components.
- Utility surfaces that still feel polished.

## Apply to NUDIMMUD

- Use Geist-like restraint for navigation, search, and board controls.
- Prefer one accent color per context.
- Build explicit empty/error states that match the rest of the shell.
