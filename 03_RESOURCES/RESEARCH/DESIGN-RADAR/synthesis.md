# Synthesis

## What the best systems share

- Clear hierarchy in the first viewport.
- Strong type scale with sparse but deliberate chrome.
- Navigation that is obvious, shallow, and stable.
- Empty states and errors that explain what happened and what to do next.
- Consistent patterns for tables, filters, and command surfaces.

## What to steal for NUDIMMUD

- Linear: velocity, calm structure, direct task surfaces.
- Vercel / Geist: crisp tokens, developer-forward minimalism, dense but controlled layouts.
- Apple HIG: hierarchy, harmony, consistency, platform-aware controls.
- Primer: enterprise clarity, responsive patterns, efficient docs style.
- Atlassian: modular foundations, AI-aware patterns, content discipline.
- Notion: flexible information architecture, wiki-style organization, layered docs.
- Framer motion assets: hover-reveal, orbital galleries, cursor-reactive tiles, scanline noise, radial selection.
- Framer University resource atlas: broad motion taxonomy with 623 examples, useful for choosing the right interaction family before building.
- Pinterest references: mood only. Use them for tone and contrast, not for layout, spacing, or component anatomy.
- Frontier Design Intelligence: unified source-selection layer across agent skills, design systems, component catalogs, galleries, repos, AI tools, and community signals.

## Practical next moves

- Put the navigation and route directive into one top bar.
- Turn the landing page into a command dashboard with one dominant action strip.
- Normalize labels to plain language.
- Add design-source notes beside each major shell module.
- Use Framer-native motion patterns when the screen needs presentation depth more than application logic.
- Load Framer motion sources before any mood board so the interaction family is decided first.
- Before each new website or UI task, load `DESIGN.md`, root `design-memory.json`, the frontier atlas, and the relevant pack; then choose 3-7 references before implementing.
- Enforce motion budget: one primary motion system, one optional ambient layer, and a reduced-motion path.
