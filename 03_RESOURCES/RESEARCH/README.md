## Promotion Rule

Move or copy a research note into this library when it has at least one of these properties:
- It changes a decision
- It supports future work
- It contains durable synthesis
- It needs to be cited later
- It is more than a temporary investigation

## Library Standard

Every durable note should ideally include:
- Scope
- Status
- Date
- Sources
- Summary
- Findings
- Open questions
- Next action

## Maintenance

- Keep the library organized by topic when the volume grows.
- Prefer links over duplication.
- Mark outdated notes clearly instead of silently replacing them.
- Add an index entry when a new durable research thread starts.
