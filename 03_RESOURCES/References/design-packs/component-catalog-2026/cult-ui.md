## SELECTED COMPONENT SPECS

### Family Button
**Deps:** framer-motion (motion), lucide-react
**Motion:** spring physics (stiffness/damping), layout animation
**Behavior:** 4rem square → 200px wide; plus icon rotates to X; content fades in with delay
**Registry:** `pnpm dlx shadcn@latest add https://cult-ui.com/r/family-button.json`
**Interface:** `children: ReactNode`

### Distorted Glass
**Deps:** vanilla CSS + SVG filters (no JS deps)
**Technique:** SVG feTurbulence (fractal noise) + feDisplacementMap — creates warping glass
**Responsive:** hidden below xl breakpoint; 600px on lg, full-width on xl
**Props:** none (presentational component)
**Registry:** `pnpm dlx shadcn@latest add https://cult-ui.com/r/distorted-glass.json`

### Dynamic Island
**Deps:** framer-motion (motion library)
**Motion:** spring stiffness=400, damping=30
**Size presets:** default, compact, large, ultra, massive
**Exports:** DynamicIsland, DynamicContainer, DynamicTitle, DynamicDescription, useDynamicIslandSize, useScheduledAnimations
**Registry:** `pnpm dlx shadcn@latest add https://cult-ui.com/r/dynamic-island.json`
