# 03_RESOURCES — Context

All assets, stock footage, LUTs, presets, plugins, templates, and reference material.

## Subfolders
- `Assets/` — project-agnostic visual assets
- `Stock/` — licensed stock footage and images
- `LUTs/` — color grading lookup tables (DaVinci/Premiere)
- `Presets/` — software presets (AE, Premiere, Resolve)
- `Plugins/` — plugin documentation and licenses
- `Templates/` — reusable project and document templates
- `References/` — visual references, mood boards, research

## Numbering Note
This directory fills the gap between `02_AREAS/` and `04_FINANCE/`. Originally lived only in the nested `YURI/` mirror; surfaced to root on 2026-05-07 as part of the structure refactor.
